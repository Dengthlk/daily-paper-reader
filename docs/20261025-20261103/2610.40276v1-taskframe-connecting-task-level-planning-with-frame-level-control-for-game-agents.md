## 摘要
构建通用游戏智能体既需要在快速变化的视觉环境中进行高层任务推理，又需要低延迟的动作控制。这两类能力适合计算特性显著不同的模型，因此难以在单一模型中同时实现。在本工作中，我们提出 TaskFrame，一个连接任务级规划与帧级键盘鼠标控制的分层规划器-控制器框架。一个视觉语言任务规划器将高层目标分解为有序的原子指令序列，并通过监督学习和依赖感知 GRPO 进行优化。终止每条原子指令的特殊目标 token 的隐藏状态提供连续目标嵌入，这些嵌入会被缓存并在各控制步骤中复用。一个因果 Transformer 控制器将当前活动目标的嵌入与近期观测相结合，以在每个游戏步骤预测离散的键盘和鼠标按键动作以及连续的相机运动。我们分三个阶段训练该系统：规划器训练、控制器预训练和联合对齐。在 Minecraft 中的实验表明，TaskFrame 在指令分解方面与通用视觉语言模型具有竞争力，并且在闭环评估中，该智能体取得了高于所评估基线的战斗成功率。

## Abstract
Building general game agents requires both high-level task reasoning and low-latency action control in rapidly changing visual environments. These capabilities favor models with substantially different computational profiles, making them difficult to realize within a single model. In this work, we present TaskFrame, a hierarchical planner-controller framework that connects task-level planning with frame-level keyboard-and-mouse control. A vision-language task planner decomposes a high-level goal into an ordered sequence of atomic instructions and is optimized through supervised learning and dependency-aware GRPO. The hidden states of special goal tokens that terminate each atomic instruction provide continuous goal embeddings that are cached and reused across control steps. A causal Transformer controller combines the embedding of the active goal with recent observations to predict discrete keyboard and mouse-button actions and continuous camera motion at every game step. We train the system in three stages: planner training, controller pretraining, and joint alignment. Experiments in Minecraft show that TaskFrame is competitive with general-purpose vision-language models on instruction decomposition, and that in closed-loop evaluation the agent achieves a higher combat success rate than the evaluated baselines.

## 2. 方法论
- **核心思想**：视觉语言规划器将高层指令分解为原子目标序列，每个原子目标以特殊 goal token 终止；该 token 的隐藏状态作为连续目标嵌入 \(z_j\) 缓存。因果 Transformer 控制器以活动目标嵌入、近期帧和动作历史为条件，每帧预测离散按键/鼠标按钮和连续相机运动。
- **规划器训练**：
  - 基于 Qwen3.5-9B，冻结视觉编码器，训练语言模型与多模态连接器。
  - **SFT**：在 GameHorizon Suite 分解标注上学习输出“原子指令 + goal token”序列；训练时通过固定推理前缀提供目标步数 \(k\)，推理时不提供。
  - **依赖感知 GRPO**：用 Hungarian 分配将生成步骤与参考步骤对齐，相似度为内容词 F1 与字符匹配率各 0.5 的加权。奖励包括步数奖励 \(R_k=\max(0,1-|\hat k-k|/k)\)，以及排序奖励 \(R_{ord}=\mathbb{1}[\hat k=k](0.8S_{dep}+0.2S_{conv})\)，最终 \(R=0.3R_k+0.7R_{ord}\)。其中 \(S_{dep}\) 衡量必须先后依赖的满足率，\(S_{conv}\) 衡量无依赖对的常规顺序一致性。GRPO 使用组内均值中心化奖励和 KL 惩罚，不除以组内标准差。
- **目标表示**：第 \(j\) 个 goal token 位置的隐藏状态 \(z_j\) 综合观测、高层指令和前序步骤，既支持可解释的文本计划，又作为控制器条件；控制器只消费 \(z_j\)，不直接消费解码文本。
- **帧控制器**：
  - 每帧 token 组包括目标嵌入 \(z\)、SigLIP 视觉 token（经 Perceiver 重采样为每帧 1 token）、动作查询 token \(a_{in}\)、动作 token \(a_t\)；因果 Transformer 在 \(a_{in}\) 位置输出 \(a^{out}_t\)。
  - **混合动作头**：键盘 26 类、最多 4 键同时，鼠标按钮 4 类、最多 2 个，均自回归解码；相机运动用轻量 flow-matching 头输出 yaw/pitch 增量，避免离散分箱。
  - 因果掩码防止同帧动作泄漏：\(a^{out}_t\) 不能 attend 同帧动作 token，且无 token attend \(a^{out}\)。
- **三阶段训练**：
  1. 规划器 SFT + 依赖感知 GRPO；
  2. 控制器预训练，目标嵌入由冻结的通用 VLM（Qwen3.5-9B）从窗口首帧和原子指令生成；
  3. 用 GRPO 规划器替换通用编码器，并在规划器语言模型中加入 LoRA，联合优化控制器与 LoRA，规划器基座权重冻结。
- **多速率推理**：任务率下规划器解码一次计划并缓存 \(z_1,\dots,z_{\hat k}\)；帧率下控制器每步仅使用活动目标嵌入和当前窗口帧/动作，20 Hz 输出动作。
