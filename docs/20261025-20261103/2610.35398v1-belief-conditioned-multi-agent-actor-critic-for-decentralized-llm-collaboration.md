## 摘要
近期研究探索了通过多智能体强化学习（MARL）优化大语言模型（LLM）协作，但许多方法仍依赖预定义的工作流，限制了效率与可扩展性。去中心化 LLM 协作具有挑战性，因为智能体在通信受限的情况下独立执行，共享一个联合目标，并且必须从通信轨迹中推断有用信息。本文提出 BCMAAC，一种基于信念条件的多智能体演员-评论家方法，该方法维护对上下文信息的信念，并利用这些信念辅助训练。在 Minecraft 游戏、网页搜索和工具使用任务上的实验表明，与朴素演员-评论家基线相比，BCMAAC 提升了任务性能和协作行为。在多轮任务中，上下文信息更丰富时改进尤为显著，此时信念建模展现出明显优势。

## Abstract
Recent work has explored optimizing LLM collaboration through Multi-Agent Reinforcement Learning (MARL), but many approaches still rely on predefined workflows, limiting efficiency and scalability. Decentralized LLM collaboration is challenging because agents execute independently with limited communication, share a joint objective, and must infer useful information from communication traces. In this paper, we propose BCMAAC, a Belief-Conditioned Multi-Agent Actor-Critic method that maintains beliefs over contextual information and uses them to facilitate training. Experiments on Minecraft game-playing, web searching and tool-using tasks show that BCMAAC improves task performance and collaborative behavior compared to naive actor-critic baselines. The improvements are particularly pronounced in multi-turn tasks with richer contextual information, where belief modeling provides a clear advantage.

## 2. 方法论：BCMAAC

### 2.1 核心思想

- 将去中心化 LLM 协作建模为合作式 **Dec-POMDP**。
- 每个智能体除语言历史 \(h_{i,t}\) 外，还接收**执行时可获得的结构化侧信息** \(x_{i,t}\)。
- 使用循环信念编码器维护隐信念：
  \[
  (c_{i,t}, z_{i,t+1}, \hat b_{i,t}, \hat p_{i,t}) = f_\psi(x_{i,t}, z_{i,t})
  \]
  其中 \(c_{i,t}\) 为信念上下文，\(\hat b_{i,t}\) 为任务信念预测，\(\hat p_{i,t}\) 为伙伴动作预测。
- Actor 以本地历史和本地信念为条件：
  \[
  \pi_{\theta_i}(a_{i,t}\mid h_{i,t}, c_{i,t})
  \]
- 训练时集中式 critic 聚合所有智能体信念：
  \[
  c_t = \mathrm{Joint}(\{c_{i,t}\}_{i\in I}),\quad V_\phi(c_t)
  \]
- 执行时仅保留 actor 和信念编码器，critic 与辅助预测头不参与，因此保持**分散执行**。

### 2.2 训练目标与辅助信号

- 优势估计采用一步 TD：
  \[
  \hat A_t = r_t + \gamma V_\phi(c_{t+1}) - V_\phi(c_t)
  \]
- Actor 损失：
  \[
  L_\pi = -\sum_t\sum_i \hat A_t \log \pi_{\theta_i}(a_{i,t}\mid h_{i,t}, c_{i,t})
  \]
- Critic 损失：
  \[
  L_V = \sum_t \left(V_\phi(c_t)-r_t-\gamma V_\phi(c_{t+1})\right)^2
  \]
- 辅助损失：
  - 任务信念预测：带掩码的 BCE；
  - 伙伴动作预测：交叉熵；
  - 部分任务还加入答案就绪度和动作偏好监督。
- 辅助标签由训练期标注规则 \(\Gamma_\xi(\tau)\) 利用完整轨迹和环境内部状态生成，属于**仅训练期可用的特权信息**。
- 信念编码器由价值损失、策略损失和辅助损失共同更新：
  \[
  \lambda_V L_V + L_\pi + L_{\text{aux}}
  \]

### 2.3 理论性质

- **Remark 4.1**：由于信念上下文在采样当前动作前已确定，将其作为策略梯度基线不改变梯度期望。
- **Proposition 4.2**：若联合信念上下文对未来的回报充分，即
  \[
  \mathbb E[G_t\mid F_t,c_t]=\mathbb E[G_t\mid c_t]
  \]
  则基于全部可用信息的价值与基于信念上下文的价值相等。
- **Remark 4.3**：辅助损失为信念编码器提供逐轮表示学习信号，在稀疏奖励任务中尤其重要。

### 2.4 算法流程概述

1. 采样任务并初始化各智能体历史、侧信息和循环状态；
2. 每轮由信念编码器生成信念上下文和辅助预测；
3. 各 actor 基于本地历史和信念上下文生成动作；
4. 环境执行联合动作并返回观测、侧信息和奖励；
5. rollout 结束后计算 TD 目标，并用标注规则生成辅助标签；
6. 训练时重算信念上下文，更新 critic、actor 和信念编码器；
7. 执行时仅使用 actor 与信念编码器进行分散决策。

## 7. 优点

- **方法设计清晰**：将信念建模

- 将信念建模为**可执行时维护、训练时可集中聚合**的中间表示，使“分散执行”与“集中训练”之间的衔接较自然；相比仅把原始交互历史喂给 critic，信念上下文提供了更紧凑、可监督的状态抽象。
- **辅助任务与主任务目标一致**：任务信念预测和伙伴动作预测不是额外任务头堆叠，而是服务于状态重建与伙伴建模，理论上通过共享信念编码器改善价值估计和策略学习。
- **消融设计有解释力**：将任务信念监督与伙伴动作监督拆开，能够说明不同辅助信号在不同任务中的相对作用，而不仅是报告完整模型的总体提升。
- **训练与执行的不对称设计合理**：训练期使用集中式 critic 和特权标注规则，执行期去掉 critic 与辅助头，符合去中心化部署约束，也避免了执行时依赖不可获得的全局信息。
- **任务选择覆盖多种协作难点**：包括资源不对称、部分可观测探索、跨语言/多源证据整合、有状态工具调用和文件系统读写分工，能够从多个角度检验信念建模的必要性。
- **实验报告相对规范**：报告 5 次独立运行的均值和标准差，统一基础模型、环境、奖励与 rollout 预算，并给出训练曲线，便于观察收敛性和稳定性。

## 9. 对后续研究的启示

- **将信念表示与通信学习结合**：当前信念主要用于 actor 条件和 critic 聚合，未来可研究智能体之间显式交换压缩信念或不确定性估计，从而在有限通信预算下提升协调效率。
- **发展可学习的辅助监督**：用自监督预测、对比学习或环境模型替代手工标注规则，减少对特权规则 \(\Gamma_\xi\) 的依赖，并提升跨任务迁移能力。
- **面向更多智能体和动态角色扩展**：可探索注意力式联合信念聚合、分层信念或图结构 critic，以缓解智能体数量增长带来的联合状态维数问题。
- **加强信用分配**：结合多步回报、资格迹、反事实基线或轮次级奖励建模，将终局奖励更细粒度地归因到通信、探索和工具调用等中间行为。
- **建立更标准的多 LLM 协作 benchmark**：统一任务、观测划分、工具权限、通信预算和评价指标，并纳入更多强基线，以便更公平地判断信念条件化方法的增益。
- **分析信念内容与可解释性**：可进一步可视化或探测信念上下文究竟编码了哪些任务状态和伙伴意图，验证其是否真正承担了“状态重建”和“伙伴建模”的功能，而不仅是额外正则化。

## 10. 总体评价

论文的核心贡献在于把多智能体 actor-critic 中的信念条件化思想引入去中心化 LLM 协作：执行时各智能体仅依赖本地历史与本地信念上下文行动，训练时通过集中式 critic 和辅助预测信号学习任务状态与伙伴状态表示。方法设计较清晰，理论讨论与消融实验能够支持“显式信念上下文有助于长时程、部分可观测协作”的主要结论；六项任务上的结果也显示其相对 MAAC 和提示式多智能体基线具有稳定优势，尤其在需要维护隐藏状态和伙伴就绪状态的任务中提升明显。

同时，论文仍属于在受控双智能体任务上的方法验证：侧信息假设、规则化辅助标签、集中式 critic 的扩展性、与更广泛 LLM-RL 方法的比较以及算力披露等方面仍有不足。总体而言，这是一项问题定位明确、方法衔接合理、实验覆盖较广但外推性仍待加强的多 LLM 协作强化学习研究。
