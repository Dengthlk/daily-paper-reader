## 摘要
去中心化多智能体系统（MAS）使大语言模型智能体能够在无集中控制的情况下进行交互。智能体需要在测试时适应其他智能体，并复用积累的经验来改进其交互策略，以应对合作、混合动机和对抗性设置中的未来交互。然而，现有方法通常针对特定交互设置开发适应机制。这引出一个核心问题：去中心化 MAS 如何支持跨交互设置的测试时适应和可靠的经验复用？我们提出 EvolveMAS，一个统一的自进化框架，支持回合内与跨回合的经验驱动适应。EvolveMAS 为每个主智能体配备一个专用的 MemoryAgent 进行测试时记忆治理，该 MemoryAgent 在主智能体推理上下文之外维护隔离的结构化记忆。EvolveMAS 将适应组织为两个互补过程：回合内在线适应与跨回合知识进化。在回合内在线适应过程中，MemoryAgent 根据交互证据更新情景记忆、语义记忆和工作记忆，以指导后续动作。在跨回合知识进化过程中，主智能体利用记忆和回合结果提炼可复用的交互知识，包括伙伴画像和用于后续回合的交互策略。在涵盖三种交互设置的五个基准和六种评估配置上，EvolveMAS 在对比方法中取得了最高的归一化平均分 77.2。消融实验表明，测试时记忆治理和跨回合知识复用均能提升性能。交互轨迹进一步说明了更新后的记忆和提炼的知识如何指导后续交互。这些结果支持去中心化 MAS 在不更新模型参数的情况下实现经验驱动适应。

## Abstract
Decentralized multi-agent systems (MAS) enable large language model agents to interact without centralized control. Agents need to adapt to other agents at test time and reuse accumulated experience to refine their interaction strategies for future interactions across cooperative, mixed-motive, and adversarial settings. However, existing approaches often develop adaptation mechanisms for particular interaction settings. This raises a central question: how can decentralized MAS support test-time adaptation and reliable experience reuse across interaction settings? We propose EvolveMAS, a unified self-evolution framework that supports experience-driven adaptation within and across episodes. EvolveMAS pairs each main agent with a dedicated MemoryAgent for test-time memory governance, which maintains isolated Structured Memory outside the main agent's reasoning context. EvolveMAS organizes adaptation into two complementary processes: Within-Episode Online Adaptation and Cross-Episode Knowledge Evolution. During Within-Episode Online Adaptation, MemoryAgent updates episodic, semantic, and working memory from interaction evidence to inform subsequent actions. During Cross-Episode Knowledge Evolution, the main agent uses memory and episode outcomes to distill reusable interaction knowledge comprising partner profiles and interaction strategies for subsequent episodes. Across five benchmarks and six evaluation configurations spanning the three interaction settings, EvolveMAS achieves the highest normalized average score of 77.2 among the compared methods. Ablations show that test-time memory governance and cross-episode knowledge reuse both improve performance. Interaction traces further illustrate how updated memory and distilled knowledge guide subsequent interactions. These results support experience-driven adaptation in decentralized MAS without updating model parameters.

## 1. 核心问题与研究动机

- **背景**：基于大语言模型（LLM）的智能体正被广泛部署，将不同用户部署的智能体连接起来可整合能力、支持跨用户协作。去中心化多智能体系统（DMAS）允许智能体基于本地信息行动、无需中央控制器即可与同伴通信。
- **三类交互设定**（按目标对齐程度划分，见图1）：
  - **合作（Cooperative）**：共享目标，如联合编码、交叉校验（BBH、HumanEval）。
  - **混合动机（Mixed-motive）**：利益部分一致、部分冲突，如谈判、社会互动（SOTOPIA、LLM-Deliberation）。
  - **对抗（Adversarial）**：目标对立、存在欺骗与隐藏意图（One Night Ultimate Werewolf）。
- **核心需求**：智能体需在测试时适应陌生伙伴，并复用积累经验改进未来交互策略——类似人类“在交互中学习”。
- **现有方法的两大局限**：
  1. **设定碎片化**：现有适应机制多针对特定交互设定/系统结构/训练流程定制，缺乏统一框架。
  2. **经验复用不可靠**：
     - **上下文膨胀（context bloat）**：长交互历史堆积在推理上下文中，损害任务表现（Du et al., 2025）。
     - **记忆污染（memory pollution）**：保留不准确的累积经验会误导后续交互（Xiong et al., 2026）。
- **研究问题**：如何构建统一机制，在合作、混合动机、对抗三类设定下同时支持测试时适应与可靠的经验复用？
- **总体思路**：走“经验驱动自进化”路线——不更新模型参数，仅靠反馈与累积经验改进行为。

## 2. 方法论：EvolveMAS 框架

### 2.1 核心思想

- **保持去中心化组织不变**：每个主智能体 $a_i$ 一对一配备专用 **MemoryAgent** $m_i$ 与**隔离记忆**；所有 MemoryAgent 共享同一记忆模式与治理协议，但内容按各自主智能体的本地交互历史独立演化。
- **三层经验抽象**：
  - 轨迹 $\tau_e$：原始交互证据；
  - 结构化记忆 $\mathcal{M}_{e,t}$：交互中维护的紧凑状态；
  - 交互知识 $\mathcal{K}_e$：跨回合可复用规律。
- **双时间尺度适应**：回合内在线适应 + 跨回合知识演化，统一在 Execute–Evaluate–Evolve（EEE）流程中。

### 2.2 EEE 流程（公式1）

对第 $e$ 回合：

- **Execute**：$(\tau_e, \mathcal{M}_e, o_e) = \mathrm{Exec}(x_e, \mathcal{A}, \mathcal{M}_{e,0}, \mathcal{K}_{e-1})$
- **Evaluate**：$r_e = \mathrm{Eval}(x_e, \tau_e, o_e)$，其中 Eval 为任务原生评估器，$r_e$ 形式可随设定变化，但提供统一接口。
- **Evolve**：$\mathcal{K}_e = \mathcal{D}_a(\mathcal{M}_e, r_e; \mathcal{K}_{e-1})$，即结果条件化的知识蒸馏。

### 2.3 回合内在线适应（公式2–3）

- 每轮 $t$：$(y_{e,t}, \Delta\tau_{e,t}) \sim \pi_a(\cdot \mid [x_e; \mathcal{M}_{e,t-1}; \mathcal{K}_{e-1}])$，随后 $\mathcal{M}_{e,t} = \mathrm{MA}_{\text{online}}(\mathcal{M}_{e,t-1}, \Delta\tau_{e,t})$。
- **结构化记忆三分区**：$\mathcal{M}_{e,t} = (\mathcal{E}_{e,t}, \mathcal{S}_{e,t}, \mathcal{W}_{e,t})$
  - **情景记忆 $\mathcal{E}$**：记录具体交互事件、涉及主体、后续结果，提供可推断规律的历史。
  - **语义记忆 $\mathcal{S}$**：维护从经验推断的可复用事实与交互规律（任务事实、协调模式、伙伴观察等）。
  - **工作记忆 $\mathcal{W}$**：维护当前交互的紧凑状态（当前焦点、下一步信息、记忆与知识的相关视图），随情境刷新。
- **更新规则**：新事件追加至情景记忆，可复用规律并入语义记忆，工作记忆按需刷新；形成“第 $t$ 轮证据→更新记忆→条件化第 $t+1$ 轮策略”的循环反馈。

### 2.4 跨回合知识演化（公式4–5）

- 回合结束后，主智能体以 $r_e$ 为条件，从 $\mathcal{M}_e$ 与 $\mathcal{K}_{e-1}$ 蒸馏出 $\mathcal{K}_e = (\mathcal{G}_e, \mathcal{P}_e)$：
  - **交互策略 $\mathcal{G}$**：指导协调、验证、谈判、信任校准等重复情境下的行为规律。
  - **伙伴画像 $\mathcal{P}$**：伙伴特定的行为倾向、推断能力与可靠性，随新证据更新。
- **双时间尺度耦合**（公式5）：
  - $\Delta\tau_{e,t} \to \mathcal{M}_{e,t} \to \text{Execute}_{t+1}$（回合内）
  - $(\mathcal{M}_e, r_e, \mathcal{K}_{e-1}) \to \mathcal{K}_e \to \text{Execute}_{\text{future}}$（跨回合）
- **关键点**：全过程不更新模型参数；记忆置于主智能体推理上下文之外，避免上下文膨胀与记忆污染。

## 6. 主要结论与发现

1. **统一框架可行**：同一套自进化协议、记忆表示与更新调度在合作、混合动机、对抗三类设定下均带来增益，无需按设定定制机制或更新参数。
2. **两个机制均有贡献**：外部记忆治理（MemoryAgent）带来主要增益（一致率 +50pp 无知识时、+40pp 有知识时），跨回合知识复用带来额外增益（+12pp / +22pp）；完整配置在 LLM-Deliberation、BBH、SOTOPIA 上均最优。
3. **经验随时间累积生效**：跨设定轨迹显示相对优势在早期不稳定后趋于持续；BBH 从初始劣势转为 +4pp 优势。
4. **外部记忆缓解上下文膨胀**：上下文占用 0.62% vs 6.54%，成本在第2回合后被 No Memory 反超。
5. **在线更新优于离线批更新**：LoCoMo 上 18.8 vs 16.4，增益集中在单跳事实召回；多跳推理上 Self-Memory 反而更强（42.7 vs 26.0），说明记忆组织方式存在权衡。
6. **知识蒸馏受模型能力制约**：弱模型可积累语义记忆但无法抽象为规则策略，差距在“抽象层级”而非“是否产生记忆”。
7. **对抗设定具零和压缩效应**：双向进化时村方胜率不反映单边增益，需单向审计归因；EvolveMAS 使胜率向受装备一方偏移，狼方增益更大。

- **问题定位清晰**：将“设定碎片化”“上下文膨胀”“记忆污染”三个痛点统一为一个研究问题，动机链条完整。
- **框架统一性强**：一套 EEE 流程 + 三分区记忆 + 两类知识，跨三类交互设定复用，工程上可作为即插即用扩展，保留智能体自治。
- **记忆外置设计巧妙**：MemoryAgent 与主智能体一对一隔离，既避免污染推理上下文，又支持每

个主智能体独立演化记忆内容，实现“共享协议、隔离内容”的可扩展组织形态。

- **双时间尺度设计有理论张力**：回合内在线适应与跨回合知识蒸馏通过 EEE 流程显式耦合，且以公式（1）–（5）形式化，使“经验驱动自进化”从隐喻变为可实现的算法对象。
- **经验抽象层次分明**：轨迹→结构化记忆→交互知识的递进，对应“证据—状态—规律”三级抽象，既保留原始证据可追溯性，又抑制冗余；语义记忆去重（56 原始条目→11 唯一）与工作记忆紧凑化（上下文占用 0.62%）从两侧验证了该设计的有效性。
- **实验覆盖面广且对照设计讲究**：三类交互设定、5 个基准、6 种配置，配合设定原生基线、Self-Memory 对照、No Memory 消融、静态 MoA 聚合四类对照，能够分别回答“是否有效”“增益来自哪里”“是否只是聚合效应”三个层次的问题；迁移基线保留原生协议与同一 runner/evaluator，公平性处理较到位。
- **对负面/边界结果坦诚**：主动报告强 lineup 下优势消失、SOTOPIA 未夺第一、多跳推理上 Self-Memory 更强、弱模型蒸馏 0 条规则等不利证据，并明确区分“数值领先”与“统计显著”，学术态度客观。
- **工程可落地性**：training-free、不改进模型参数、MemoryAgent 可替换为小模型（GPT-4o-mini），对实际部署的改造成本低，且与现有 DMAS 框架兼容。

## 8. 局限与不足

- **统计效力不足**：主表多数条件为单次运行，无方差/置信区间；作者自述 HumanEval、SOTOPIA 的差异与运行噪声同量级，LLM-Deliberation 上 Self-Memory 与原生基线 95% 区间含零。因此“4 项第一、2 项第二”的排序结论稳健性有限，部分增益可能不可复现。
- **结论对基线饱和度敏感**：BBH 强 lineup 下 EvolveMAS（82.0）反低于 AgentNet（84.0），21 组比较仅 1 组显著且未做多重比较校正。这说明当底层模型能力接近任务上限时，外部记忆与知识蒸馏的边际收益可能转负（引入额外推理开销与噪声），方法的适用边界未被清晰刻画。
- **算力与成本透明度不足**：未报告 GPU 型号/数量/总推理调用量，仅给出 SOTOPIA 单场景每回合货币成本；缺少跨基准的统一成本—收益分析（如“每提升 1 分需要多少额外 token/美元”），难以评估大规模部署的经济性。
- **记忆治理缺少失效分析**：论文展示了记忆带来的增益，但对“记忆污染”这一核心动机的反面证据（如错误语义条目被写入后如何被检测/回滚、伙伴画像误判的传播）着墨较少；三分区记忆的更新规则偏启发式，缺少对写入阈值、冲突消解、遗忘机制的消融。
- **知识蒸馏的能力门槛未被系统刻画**：附录 D 显示弱模型蒸馏 0 条规则，但仅覆盖单一弱模型（Qwen3-14B）与单一任务，未给出“何种能力水平/何种任务结构下蒸馏有效”的判据，限制了方法的可预期性。
- **多跳推理存在权衡未被解决**：LoCoMo 上 Self-Memory 多跳 42.7 vs EvolveMAS 26.0，说明外置结构化记忆在需要跨条目整合的推理上可能损失信息；论文将其作为观察报告，未提出针对性改进。
- **对抗设定评估受零和压缩影响**：双向进化使胜率相互抵消，单向审计虽缓解归因问题，但四配置各 100 局、两局差距被作者自己定性为数值领先，对抗设定的结论强度弱于合作/混合动机设定。
- **伙伴画像的泛化性存疑**：$\mathcal{P}_e$ 为伙伴特定画像，跨回合复用依赖“同一伙伴再次出现”的假设；在开放部署中伙伴高度异质、重复率低时，画像的迁移价值与污染风险均未被评估。

## 9. 启发与可借鉴点

- **“记忆外置 + 协议共享”的组织范式**：将记忆管理从主智能体推理上下文中剥离，交给一对一专用 MemoryAgent，同时让所有 MemoryAgent 共享同一模式与治理协议。这一“共享协议、隔离内容”的设计可迁移到任何多智能体/多会话系统，用于同时解决上下文膨胀与经验污染。
- **三级经验抽象（轨迹/记忆/知识）可作为通用表示**：把“原始证据—紧凑状态—可复用规律”分层，并在每层设定明确的写入与刷新规则，为 agent 经验管理提供了可复用的数据模型；尤其适合需要审计追溯的场景（原始轨迹保留）。
- **EEE 流程是低改造成本的自进化模板**：Execute–Evaluate–Evolve 将“任务原生评估器”作为统一接口，使同一协议可套用到准确率、pass rate、谈判同意方数、胜率等异构奖励，值得作为多设定实验的标准骨架。
- **2×2 因子消融的归因思路**：以“记忆治理 × 跨回合知识”两轴分离两个机制的边际贡献，并在多个基准重复，是评估复合框架时值得借鉴的消融设计；相比逐模块删除，因子设计能揭示交互效应。
- **单向审计用于零和设定归因**：在对抗场景中固定一方策略、只让另一方进化，可将“双向进化下的胜率抵消”还原为单边增益，是评估对抗性多智能体方法的实用技巧。
- **能力分层沉淀分析**：按模型强弱分别统计蒸馏出的规则数量与语义条目冗余度，揭示“记忆可产生但规律不可抽象”的失效模式，为方法设定能力前提提供了可操作的诊断手段。

## 10. 总体评价

EvolveMAS 针对“去中心化多智能体系统如何跨异质交互设定实现测试时适应与可靠经验复用”这一问题，提出了结构清晰、形式化完整且工程可落地的统一框架。其核心贡献在于：把记忆治理外置为独立的 MemoryAgent 组织形态，配合三分区结构化记忆与双时间尺度的知识蒸馏，在不更新模型参数的前提下统一覆盖合作、混合动机、对抗三类设定，并在 5 个基准、6 种配置上取得归一化平均分第一（77.2）。2×2 因子消融有效分离了两个机制的贡献，系统级分析（上下文占用 0.62% vs 6.54%、成本反超）为“外置记忆缓解上下文膨胀”提供了直接证据。

同时，论文的证据强度受限于单次运行、无方差估计、强 lineup 下优势消失、部分对照不显著等问题，对抗设定与多跳推理上还存在明确的权衡未被解决；算力与成本报告亦不够透明。因此，更稳妥的定位是：**该工作提供了一个有说服力的“统一框架可行性”论证与一套可复用的设计范式，但其相对设定特定基线的稳健优势仍需多种子、多模型规模、跨伙伴分布的重复实验来确认**。对于后续研究，最有价值的方向包括：记忆写入/冲突消解/遗忘机制的显式建模、知识蒸馏能力门槛的刻画、以及外置结构化记忆在多跳整合推理上的补偿设计。
