## 摘要
交互式环境为评估大语言模型（LLM）智能体提供了一种实用方式，而竞争性游戏将这种评估扩展到由竞争目标和其他智能体选择所塑造的决策。然而，现有评估局限于单个游戏或执行框架，使得哪些竞争优势能够跨设置持续存在仍不明确。我们提出 DECE（Diverse Eurogame Competitive Environments，多样化欧式桌游竞争环境），一个涵盖十款欧式桌游、具有共享接口和评估协议的统一竞技场。这些游戏结合了持久战略承诺、对共享资源的竞争以及多种获胜路径。我们的主要研究评估了12种模型-执行框架配置，涵盖九个模型和四种执行框架，在十款游戏中进行480场三人对局。主要研究和补充研究共包含1,032场完成的对局。这些比较揭示了跨游戏排名总体一致，同时也存在游戏特定的优势。匹配研究表明，同一模型在不同执行框架下可能表现不同，为这些画像增加了另一变异来源。这些性能优势并不总能转化为更好的token或成本效率，因此在比较配置时资源使用是另一项考虑因素。总体而言，研究结果支持从跨游戏的竞争性能以及实现该性能所需资源两方面来评估完整的智能体配置。

## Abstract
Interactive environments offer a practical way to evaluate large language model (LLM) agents, and competitive games extend this evaluation to decisions shaped by competing goals and other agents' choices. Yet existing evaluations confined to individual games or execution frameworks leave unclear which competitive advantages persist across settings. We introduce DECE (Diverse Eurogame Competitive Environments), a unified arena spanning ten Eurogames with shared interfaces and evaluation protocols. These games combine lasting strategic commitments, competition over shared resources, and multiple routes to victory. Our primary study evaluates 12 model-harness configurations, spanning nine models and four execution harnesses, in 480 three-player matches across ten games. The main and supplementary studies comprise 1,032 completed matches in total. These comparisons reveal broad cross-game ranking agreement alongside game-specific strengths. Matched studies show that the same model can perform differently across execution harnesses, adding another source of variation to these profiles. These performance advantages do not consistently translate into better token or cost efficiency, making resource use an additional consideration when comparing configurations. Together, the findings support evaluating complete agent configurations by both their competitive performance across games and the resources needed to achieve it.

## 1. 核心问题与研究动机

- **背景**：LLM 智能体正越来越多地通过工具在外部环境中行动，交互式基准用于评估其在长轨迹上的决策。竞争性游戏进一步引入"对手也有自身目标并改变你的可选机会"这一要素，行动价值同时取决于未来后果与对手选择。
- **核心问题**：*如何构建竞争性环境，以对完整智能体系统在多样战略需求下进行可靠评估？*
- **现有缺口**：
  - 现有评测多局限于**单一游戏**或**单一执行框架**，无法判断哪些竞争优势能跨设置持续存在；
  - 同一模型在不同执行框架（harness）下的表现差异未被系统刻画；
  - 性能优势与资源（token/成本）效率之间的关系缺乏联合分析。
- **为何选欧式桌游（Eurogames）**：规则明确、状态与动作可程序化执行、结果可独立验证；同时具备**持久战略承诺**（如 Splendor 发展卡永久降低后续购买成本）、**共享机会竞争**、**多条获胜路径**，可形式化为部分可观测随机博弈（POSG）。
- **整体含义**：主张评估单元应是**完整的"模型–执行框架"配置**（含提示、工具、记忆、推理设置、资源预算），而非孤立的模型，并需同时报告跨游戏竞争表现与资源消耗。

## 2. 方法论：DECE 框架

### 2.1 核心思想
构建一个覆盖十款欧式桌游的**统一竞技场**，通过共享接口连接游戏与可插拔的执行框架，在统一参与者名单、座位平衡协议与可验证结果下进行跨游戏比较。

### 2.2 游戏套件（10 款，按主导战略需求分三组）
- **容量构建（Capacity）**：Splendor、Century: Spice Road、Wingspan
- **空间承诺（Spatial）**：Azul、Harmonies、Carcassonne
- **多系统协调（Coordination）**：7 Wonders、The Castles of Burgundy、Brass: Birmingham、Ark Nova
- **六维机制标注**（0/1/2 = 缺失/有限/突出）：引擎构建（EC）、空间规划（SP）、行动排序（AS）、对手耦合（OC）、隐藏信息（HI）、得分协调（SC）。用于组织描述性跨游戏比较。
- **交互长度差异大**：整局决策数中位数从 7 Wonders 的 54 到 Ark Nova 的 473。

### 2.3 统一接口与参与者抽象
- 共享接口覆盖：初始化、**座位特定观测**、合法动作、状态转移、终局排名。
- 引擎强制执行规则与计分；**同时决策**采用冻结状态、待所有座位提交后统一推进；公共信息、私有状态、未揭示随机性严格分离。
- 通过 **MCP 与原生适配器**暴露接口；持久化状态与执行记录支持审计、回放与恢复。
- 每个参与者 = 模型快照 + 执行框架 + 提示 + 工具 + 记忆范围 + 推理设置 + 资源预算。

### 2.4 竞争结果度量
- **PWS（Pairwise Placement Score，两两排位得分）**：击败对手的比例，平局记半分：
  $$u_{it}=\frac{1}{n_t-1}\sum_{j\neq i}\left[\mathbb{1}(r_{it}<r_{jt})+\tfrac12\mathbb{1}(r_{it}=r_{jt})\right]$$
  均值 PWS 对十款游戏**等权**。
- **Elo 评分**：基于 Bradley–Terry 模型拟合正则化评分：
  $$p_{ij}=\frac{1}{1+10^{(E_j-E_i)/400}},\quad E_i=1500+\frac{400}{\ln 10}\theta_i,\quad \sum_i\theta_i=0$$
  三人对局中每对权重为 1/2，惩罚项 $0.02\sum_i\theta_i^2/2$，牛顿法优化。
- **不确定性**：按整局重采样（bootstrap），保留同局对手与终局结果一起重抽；每游戏 5,000 次。

### 2.5 资源核算与前沿分析
- 记录输入+输出 token（缓存输入、推理 token 各计一次）与**API 等效成本**：
  $$C=10^{-6}\{p_{in}(I-H)+p_{cache}H+p_{out}O\}$$
  采用固定价格表（2026-08-28，6.7811 CNY/USD）。
- **Pareto 前沿**：每游戏比较 Elo 与平均成本/平均 token，保留非支配配置；给出预算 $B$ 下的最优 Elo 阶梯：
  $$V_g(B)=\max_{i:C_{ig}\le B}E_{ig}$$

### 2.6 匹配研究设计（RQ2）
- 固定 setup seed、焦点座位、锚点对手配置，在场景内做配对比较；
- 定义同模型跨框架差值 $\delta_g$、组均值差 $\Gamma=\Delta_G-\Delta_H$（G = 4 个"公共信息+空间"游戏，H = 其余 6 个），并做删一游戏敏感性分析。

## 6. 主要结论与发现

1. **跨游戏排名总体一致**：九游戏均值 PWS 排名与留出游戏的 mean Kendall τb = **0.664**，成对顺序准确率 **83.9%**（单游戏 τb 0.489–0.862）。
2. **存在明显的游戏特异性优势**：
   - GPT-5.6-Sol/OpenCode 与 /Codex 领先（75.6% / 75.4%），且每款游戏均 >50%；
   - Qwen3.8-Max/Qwen Code 均值 70.2%，但在 Azul、Harmonies、Carcassonne 排第一、Burgundy 第二（四款"公共信息+空间"游戏均值 84.9%）；
   - GPT-5.6-Terra/Codex 在 Century/Brass/Ark Nova 强（均值 75.0%），在 Azul/Harmonies/Carcassonne 弱（36.8%），总均值 50.2% 掩盖了这种分化。
3. **单一机制标签无法概括画像**：Brass、Ark Nova 同样有强空间约束，但 Qwen3.8-Max 仅排第六、第八；说明需考察"承诺+信息+行动依赖"的组合。
4. **框架效应真实存在但局部**：同一模型换框架表现可大幅变化——Qwen3.8-Max 在 Splendor 从 OpenCode 的 33.3% 升至 Qwen Code 的 91.7%（+58.3 pp，6/6 场景全胜）；但跨游戏方向不一致（7 Wonders 仅 +8.3 pp）。
5. **性能优势≠资源效率**：
   - GPT-5.6-Luna/Codex 与 DSV4-Pro/DSH 出现在全部 10 个成本前沿，但 token 前沿分别只有 3 个和 2 个；
   - Kimi-K2.7-Code 相反：6 个 token 前沿、0 个美元前沿；
   - Qwen3.8-Max/Qwen Code 在高成本端（Wingspan Elo 1837，$89.25），但在 Burgundy/Ark Nova 被支配。
6. **总体主张**：应以"跨游戏竞争表现 + 所需资源"共同评估完整智能体配置，并辅以游戏级画像而非仅看聚合排名。

## 7. 优点与亮点

- **评估单元的前瞻性**：把"模型+框架+工具+上下文管理"作为整体评估，直击"同一模型换框架结果不同"这一被忽视的变异源。
- **统一接口与可审计性**：MCP/原生适配器、版本化状态、SQLite 持久化、状态哈希、回放/恢复，工程严谨度高。
- **游戏选择的机制多样性**：

- **游戏选择的机制多样性**：十款游戏在六维机制标注上形成互补覆盖（引擎构建、空间规划、行动排序、对手耦合、隐藏信息、得分协调），且交互长度跨度大（中位决策数 54–473），使"跨设置持续性"这一核心主张可被实证检验，而非停留在设计宣称。
- **度量设计的稳健性考虑**：PWS 采用等权游戏平均，避免长局游戏因决策数多而主导总体排名；Elo 用正则化 Bradley–Terry 拟合并处理三人对局的两两权重；不确定性用整局重采样而非独立样本重采样，保留同局相关性。
- **资源口径的双重报告**：同时给出 token 与 API 等效成本，并明确价格表与汇率时点，降低单一计价假设带来的误导；Pareto 前沿与预算–Elo 阶梯 $V_g(B)$ 把"性能–成本"从描述性对比提升为可查询的决策工具。
- **匹配研究的因果化努力**：通过固定种子、焦点座位、锚点对手与场景内配对比较来控制对手样本差异，并显式定义跨框架差值 $\delta_g$ 与组均值差 $\Gamma$，再用删一游戏敏感性分析检验结论是否由单一游戏驱动——这是同类 LLM 竞技评测中较少见的严谨处理。
- **可复现与可审计**：终局记录完整性校验、PWS 单元可由终局排名精确复算、Codex 原生会话日志全覆盖主队列，使结果具备第三方复核的可能性。
- **诚实的负面/无效结果报告**：明确报告框架效应在 Bonferroni 校正后多不显著、单元级置信区间偏宽，未将"方向一致"夸大为"统计显著"。

## 8. 不足与局限

### 8.1 统计功效与推断强度
- **样本量偏小导致区间过宽**：每"配置–游戏"单元仅 12 次出现，Splendor 部分配置的 PWS 置信区间跨度可达 50 pp，难以支撑精细的配置间排序；论文的主要结论因此更多是"排名结构一致性"层面的，而非"某配置显著优于某配置"层面的。
- **多重比较压力**：框架对比涉及多游戏 × 多模型 × 多场景，Bonferroni 校正后多数交互效应不显著（如 Qwen3.8-Max/Splendor 校正后 p=0.125），意味着"框架效应真实存在"这一判断在个别亮眼案例（+58.3 pp）上依赖点估计而非显著性。
- **聚合指标与个体画像的张力**：总均值会掩盖分化（GPT-5.6-Terra/Codex 总均值 50.2% 但组间从 36.8% 到 75.0%），论文虽以游戏级画像补救，但等权平均本身仍是一种规范性选择，未讨论替代加权（如按决策数、按机制覆盖度加权）对排名的影响。

### 8.2 生态效度与外部有效性
- **玩家数覆盖有限**：主队列固定三人对局，2 人/4 人仅覆盖 Splendor、Brass、7 Wonders 三款，关于"竞争结构变化如何影响配置优势"的结论外推能力有限；而二人零和与三人非零和的策略性质差异显著。
- **基线与主队列不同场**：Random / Heuristic / ISMCTS 为独立 60 场队列，仅提供大致竞争定位，无法回答"LLM 配置是否在同等对手池中击败搜索基线"这类同场对照问题。
- **模型与框架的快照性**：结论绑定于特定模型快照、提示、工具集与推理设置；论文自身主张评估单元是完整配置，这也意味着结论的时效性与可迁移性受版本漂移制约，跨版本可比性需要持续复测。
- **成本口径的假设依赖**：API 等效成本基于固定价格表与汇率，实际部署（自托管、批处理折扣、缓存策略差异）下成本排序可能改变；token 前沿与美元前沿的配置分歧（如 Kimi-K2.7-Code 6 个 token 前沿、0 个美元前沿）本身也提示价格假设的敏感性未被系统压力测试。

### 8.3 机制归因的深度
- **机制标签为描述性而非解释性**：六维 0/1/2 标注用于组织比较，但论文亦承认单一标签无法概括画像（Brass、Ark Nova 空间约束强，Qwen3.8-Max 却排第六、第八），说明"为何某配置在某游戏强"仍缺乏可检验的因果机制模型，当前更接近事后归因。
- **未拆解框架内部组件**：框架效应被证明存在，但框架内部的提示模板、工具调用循环、上下文压缩、错误恢复策略各自贡献多少未被消融；这限制了"如何改进框架"的可操作指导。
- **对手建模与长程承诺的测量缺失**：论文强调持久战略承诺与对手耦合是欧式桌游的关键，但未提供针对"承诺兑现率""对手意图推断准确度"等中间过程的诊断指标，胜负结果与策略质量之间仍有黑箱。

## 9. 启示与展望

- **对评测实践**：应将"模型–执行框架"配置作为报告单元，至少同时披露跨游戏排名分布（而非单一均值）、座位/种子协议、资源消耗与置信区间；单游戏榜单不足以支撑选型决策。
- **对智能体研发**：框架层（上下文管理、工具编排、错误恢复）是可与模型能力分离优化的显著杠杆，尤其在特定游戏上可产生数十个百分点的差异，值得作为独立工程对象投入。
- **对基准设计**：机制多样性 + 交互长度跨度 + 共享机会竞争的组合，是检验"优势是否跨设置持续"的有效配方；未来可扩展到非零和、多玩家、含谈判/联盟的博弈，以及需要跨局记忆的连续赛事设定。
- **对后续工作**：提高每单元对局数或采用自适应分配以收窄区间；做框架组件的消融归因；引入过程级诊断指标（承诺兑现、对手建模质量）；在同一对手池中混合 LLM 配置与非 LLM 基线以强化竞争定位。

## 10. 总体评价

DECE 的核心贡献不在于"哪个模型最强"的排行榜，而在于**把评估对象从模型上移到完整智能体配置**，并用统一接口、座位平衡、可审计状态与资源前沿分析把这一定位落到可执行的实验协议上。其证据足以支持两条中等强度结论：（i）跨游戏竞争表现存在可观的排序一致性（mean Kendall τb = 0.664，成对顺序准确率 83.9%），（ii）框架效应真实且局部显著，但方向随游戏而异。相对薄弱之处在于统计功效（单元 12 次、区间宽）、机制归因的描述性以及基线的非同场设置。作为评测基础设施与方法论示范，其价值高于其单次排名结果；建议读者将本文视为"如何评估智能体系统"的模板，而非"某模型优于某模型"的定论。
