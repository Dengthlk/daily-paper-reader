## 摘要
Balatro 是一款 2024 年的 roguelike 牌组构建游戏，它带来了三类历来会使强化学习方法失效的困难：依赖状态的约 3,000 个动作的动作空间、具有稀疏奖励且长达数百个决策的决策时域，以及卡牌抽取和商店生成中普遍存在的随机性。该游戏已发表的强化学习结果仍然稀少。我们提出一个端到端流水线，包括：(i) 一个高吞吐量的 Rust 模拟器，通过 BalatroBot 与实时游戏客户端自动进行状态差异比对；(ii) 一个精简的观察-动作接口，并在每一步动态屏蔽非法动作；(iii) 一个多智能体 PPO 架构，将游戏分解为战术性盲注策略和战略性商店策略，二者共享完整游戏状态但在互不重叠的阶段行动。长时程信用分配通过按智能体路由奖励并显式引入跨智能体信用得到部分解决。在主要的联合训练运行中，训练指标显示出急剧的相变：第一盲注通过率收敛至 99% 以上，平均回合回报提高约一个数量级，并在平均最大底注为 8 中的 3 处趋于平台；在相同奖励下，单智能体基线在贪婪与囤积两种失败模式之间振荡，未能稳定通过第一盲注。这些结果确立了双策略分解作为 Balatro 的一个强反应式基线，并将剩余差距定位为长时程战略规划，而非战术性盲注打法。

## Abstract
Balatro, a 2024 roguelike deckbuilder, presents three difficulties that have historically derailed reinforcement learning methods: a 3,000-action state-dependent action space, horizons of several hundred decisions with sparse rewards, and pervasive stochasticity in both card draws and shop generation. Published RL results on the game remain scarce. We introduce an end-to-end pipeline comprising (i) a high-throughput Rust simulator that is automatically state-diffed against the live game client via BalatroBot, (ii) a condensed observation-action interface with dynamic per-step masking of legal moves, and (iii) a multi-agent PPO architecture that decomposes play into a tactical blind policy and a strategic shop policy that share the full game state but act in disjoint phases. Long-horizon credit assignment is partially addressed by per-agent reward routing with explicit cross-agent credit. On the main joint run, training metrics show a sharp phase transition in which the first-blind clear rate converges above 99% and mean episode return increases by roughly an order of magnitude, plateauing at a mean maximum ante of 3 out of 8; single-agent baselines under identical rewards oscillated between greedy and hoarding failure modes and did not stably clear the first blind. These results establish the two-policy decomposition as a strong reactive baseline for Balatro and localise the remaining gap to long-horizon strategic planning rather than tactical blind play.

## 二、方法论

### 2.1 总体思路

- 构建 **Rust 高速模拟器**，通过 Python 绑定供训练使用。
- 提供“最大化”动作/观察接口（约 3,000 动作、20,000 维观察），再用 Python 翻译层按实验需要压缩与掩码。
- 采用 **双策略多智能体 PPO**：盲注策略负责打牌/弃牌，商店策略负责购买、售卖、开包、选盲等；两者共享完整游戏状态，但在互不重叠的阶段行动。

### 2.2 模拟器与接口

- **模拟器实现**：Rust 核心逻辑 + Python bindings；核心 API 包括 `Reset`、`Step`、`Get State`。
- **保真度验证**：
  - 将 Rust 模拟器编译为 WebAssembly，做浏览器端可视化调试。
  - 与 BalatroBot 集成，自动逐步比对模拟器与真实游戏客户端的状态差异。
  - 记录动作轨迹用于 bug 复现与回归测试。
- **动作掩码**：每一步根据游戏阶段、资源（金钱/槽位）、手牌存在性动态生成合法动作掩码，避免在非法动作上浪费采样。
- **V1 子集**：动作空间压缩为 **74 个离散动作**，观察空间压缩为 **1,449 维**；对动态槽位采用固定缓冲区加 padding 处理，无法表示无限扩展。

### 2.3 核心奖励设计

- 事件驱动、低方差：
  - 打出牌后若筹码达到目标：奖励 **+1**。
  - 未过关但仍有出牌次数：奖励为该次出牌筹码 / 盲注目标，**上限为 1**。
  - 手牌耗尽未过关、或非终止状态无合法动作的僵局：**-1**。
  - 非法动作：**-1** 但不终止（实际被掩码层拦截，主要作为安全网）。
  - 商店进入/离开、弃牌、兑现、重掷、调整顺序等：**0**。
- 更密集的信号全部在 Python 包装层叠加，便于与基础奖励做消融。

### 2.4 双策略架构

- **盲注策略**：
  - 输入：最多 10 张手牌、最多 8 张小丑牌、盲注/回合标量、可用牌型辅助向量。
  - 编码：`UniversalCardEncoder` 将卡牌身份、花色、点数、强化、版本、封印、debuff 等嵌入求和；花色/点数嵌入包含动态关系特征（同点数数量、同花色数量、同花可能性、顺子相邻性、正弦点数编码）。
  - 表示：手牌 + 特殊 context token 经 Transformer 自注意力，context token 输出作为手牌摘要；小丑牌经小 MLP 池化为摘要；三者拼接后过 MLP backbone。
  - 动作头：**自回归**——先决定“出牌/弃牌”，再逐张决定加入选牌或停止提交，避免在扁平 softmax 上爆炸。
  - 价值头：两层 MLP。
- **商店策略**：
  - 输入分为四组：状态摘要（金钱、回合、牌组统计、盲注嵌入、小丑数量/容量、各牌型得分统计）、商店商品、已拥有物品、已打开卡包内物品。
  - 编码：复用同一 `UniversalCardEncoder`，每个物品 token 附加动作标签（buy/sell/use/move/pack-select）与槽位 id；加入可学习的 shop-context token 作为 CLS；将状态摘要投影后广播加到所有 token。
  - 表示：多头注意力堆栈；context token 输出作为摘要。
  - 动作头：物品级动作通过“意图向量”与物品嵌入点积打分，具备位置不变性；抽象动作（重掷、结束商店、选/跳盲注、兑现、重掷 Boss）由单独 MLP 打分；两路 logits 拼接后用 -∞ 掩码非法动作。
  - 价值头：与动作头共享 shop-context 表示。

### 2.5 每智能体奖励路由

- **盲注智能体**的六个密集信号：
  - 牌型质量奖励（鼓励高牌型）；
  - 弃牌信用（弃牌后若最终有筹码进展给部分信用）；
  - 紧迫性项（剩余出牌次数越少，奖励缩放越大）；
  - 渐进式失败惩罚（走得越远惩罚越轻）；
  - 按底注缩放的过关奖励；
  - 剩余出牌次数通关的效率奖励。
- **商店智能体**的两个信号：
  - 利息层级保持惩罚（花钱跨越 5 美元利息边界时扣分）；
  - 小丑牌增长奖励（鼓励增加小丑数量）。
- **跨智能体信用**：
  - 盲注通关带来的现金与回合奖励记给商店智能体；
  - 整局胜利奖励同时给两个智能体。

### 2.6 训练设置

- 使用 Ray RLlib 多智能体 PPO；每个 worker 运行一个游戏实例，按阶段路由观察与奖励。
- 4 个 env-runner 进程（每个 1 环境）→ 单个 NVIDIA RTX A5000 learner。
- 主要超参：
  - 每次迭代 5,120 环境步，4 个 SGD epoch，minibatch 512（约 40 次梯度更新/迭代）；
  - 学习率 3×10⁻⁵ 恒定；PPO clip 0.15；value clip 3.0；value loss 系数 0.25；梯度范数裁剪 3.0；γ=0.99；GAE 默认。
  - 盲注熵系数恒为 0.001；商店熵系数 0.02 → 0.006（1.5M 步）→ 0.001（4M 步）。
- 主运行 4,000 次 PPO 迭代，约 **20.5M 环境步**，每 10 次迭代保存 checkpoint；确定性评估每次 32 局、关闭探索。

## 六、主要结论与发现

- **双策略分解有效**：联合训练后第一盲注通过率收敛到 **99% 以上**，平均回合回报提升约一个数量级。
- **三阶段学习轨迹**：
  - 前约 150 次迭代：低技能阶段，回合回报 <1，首盲通过率接近 0，回合长度约 20–27 步，金钱停留在初始 $4，最大底注为 1。
  - 约 150–400 次迭代：急剧相变。首盲通过率在第 151 次迭代越过 0.5、第 160 次到 0.9、第 173 次到 0.99；平均回报从约 5.2 峰值近 9；回合长度从约 25 升至约 150 步；终止金钱从 $4 升至约 $11；平均最大底注从 1 升至约 2.1。
  - 约 400 次迭代后：进入平台期。平滑回报约 7.6，首盲通过率约 0.998，回合长度 170–200 步，终止金钱约 $10–$12，平均最大底注约 2.6–3.0。
- **尚未通关**：完整游戏有 8 个底注，智能体平均最高仅到约 **3/8**，说明其擅长战术性盲注操作，但尚未具备完整长时程战略规划能力。
- **单智能体失败模式**：在相同奖励下于贪婪与囤积之间振荡，无法稳定通过首盲，支持“两个子问题需要不同参数化”的动机。
- **剩余瓶颈定位**：差距主要在长时程战略层（经济管理、跨盲注协同、卡组构建），而非战术盲注打牌。
