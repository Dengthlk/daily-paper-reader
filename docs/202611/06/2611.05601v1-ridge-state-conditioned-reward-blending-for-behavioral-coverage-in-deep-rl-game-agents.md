## 摘要
在固定人格奖励上训练的深度强化学习智能体只会以一种方式游玩：探索者会一直探索直到饿死，生存者会在空地图上囤积资源。由于每个人格固定自身奖励，自动化游戏测试需要为 N 种风格训练 N 个智能体。在回合中途改变奖励组成会陷入切换稳定性困境：PPO 在非平稳奖励下性能退化。我们提出 RIDGE，一种单智能体架构，通过两个设计选择绕开该困境：一个状态条件化混合器，从缓慢变化的状态变量计算经 softmax 归一化的 sigmoid 权重；以及一个多头评论家，为每个人格在其自身的平稳信号上训练一个价值头。在具有四个人格的 Crafter 环境中，一个 RIDGE 智能体习得了木材层级制作/战斗分支的两条路径，而没有任何固定人格基线能同时解决；一项锐度消融确认状态条件化驱动了该增益。我们将这些结果定位为在每种条件 n=3 个随机种子下对混合机制动态的演示；更大规模的多随机种子扫描仍属未来工作。

## Abstract
A deep RL agent trained on a fixed persona reward plays one way: an Explorer keeps exploring while starving, a Survivor hoards on an empty map. Since each persona fixes its own reward, automated playtesting trains N agents for N styles. Changing reward composition mid-episode runs into the switching-stability dilemma: PPO degrades under non-stationary rewards. We present RIDGE, a single-agent architecture that sidesteps the dilemma with two design choices: a state-conditioned blender that computes softmax-normalized sigmoid weights from slow-moving state variables, and a multi-head critic that trains one value head per persona on its own stationary signal. On Crafter with four personas, one \ridge agent acquires both branches of the wood-tier crafting/combat split that no fixed-persona baseline solves jointly, and a sharpness ablation confirms state-conditioning drives the gain. We position these results as demonstrations of the blending mechanism's dynamics across n=3 seeds per condition; larger multi-seed sweeps remain future work.

# RIDGE 论文结构化总结

## 1. 核心问题与研究动机

- **背景**：在游戏自动化测试（automated playtesting）中，业界常用“程序化人格”（procedural personas）来覆盖不同玩法风格：为每个人格（Explorer / Survivor / Craftsman / Warrior）设计一套固定奖励，训练一个独立智能体，部署时取行为并集。
- **问题一：线性扩展成本**。N 种人格需要 N 次训练、N× 环境步数，且每个智能体只表现出单一风格（“探索者会一直探索直到饿死，生存者会在空地图上囤积资源”）。
- **问题二：缺失回合内动态**。真实玩家会在一次游玩中在多种风格间切换（饿了找食物、吃饱后继续探索），固定人格无法刻画这种回合内（within-episode）转变。
- **问题三：切换稳定性困境（switching-stability dilemma）**。最直接的修法是回合内按状态改变奖励组成，但 PPO 的价值函数需要准平稳（quasi-stationary）信号；硬切换奖励会破坏收敛（Li 2026 在 LLM 引导的卫星调度中记录该现象；Moalla et al. 2024 从表征侧指出 PPO 在非平稳下会损失特征秩与容量）。
- **论文定位**：提出 RIDGE（Reactive Inter-persona Dynamic Goal Engine），用单智能体架构在回合内平滑、按状态地混合人格奖励，同时不破坏 PPO 的价值学习。

## 2. 方法论

### 核心思想
不做“回合间换人格”，也不做“硬切换奖励”，而是用**由游戏状态内部计算出的连续混合权重**在回合内平滑调配多个人格奖励，并用**每人格一个价值头**把价值学习与非平稳的混合信号隔离。

### 三个组件

- **（1）设计者撰写的人格奖励** \(r_i^t(s_t,a_t,s_{t+1})\)，\(P=\{E,S,C,W\}\)
  - Explorer：新地块发现，按地块给衰减 bonus；
  - Craftsman：新解锁的制作成就，幅度按科技树深度缩放；
  - Warrior：战斗成就，同样按科技树深度缩放；
  - Survivor：对生命/食物/饮水/能量四维 vitals 做逐步 shaping，低于阈值给“悬崖惩罚”，另有事件奖励（如 `wake_up`）。
  - 强调可读性：设计者能读懂每个 \(r_i\) 对应的玩法意图。

- **（2）状态条件化混合器（state-conditioned blender）**
  - 每个人格由慢变状态特征得到一个激活值 \(\sigma_i^t\in[0,1]\)：
    - \(\sigma_E\) = 新颖度 novelty(\(s_t\))
    - \(\sigma_S = 1-\min(h_t,f_t,d_t,e_t)\)（vitals 越差越高）
    - \(\sigma_C\) = craft_progress(\(s_t\))
    - \(\sigma_W\) = enemy_proximity(\(s_t\))
  - 原始权重：\(w_i^t=\mathrm{sig}\big(\alpha k_i(\sigma_i^t-b_i)\big)\)，其中 \(b_i\) 为人格偏置、\(k_i\) 为人格尺度、\(\alpha>0\) 为全局锐度；
  - 归一化：\(\tilde w_i^t = w_i^t / \sum_j w_j^t\)（对 sigmoid 做求和归一化，落在单纯形上）；
  - 聚合奖励 \(\bar r_t=\sum_i \tilde w_i^t r_i^t\)。
  - **两个关键性质**：① \(\tilde w\) 随状态连续变化 → 聚合奖励在邻近状态间平滑变化，满足 Li 意义下的“准平稳”；② 权重由状态**内部**产生，区别于 MultiGAIL（外部混合系数）与 HDPG（训练进度调度）等外部信号方案。
  - **锐度 \(\alpha\) 的语义**：\(\alpha\to0\) 退化为均匀混合（\(\tilde w_i=1/|P|\)）；\(\alpha\to\infty\) 逼近对 \(\sigma_i\) 的硬 argmax，即回到 Li 警告的硬切换区间。

- **（3）多头评论家 + PPO**
  - 单一策略 \(\pi_\theta(a_t|s_t)\)，共享编码器之上挂 \(|P|\) 个价值头 \(V_\phi^i\)；
  - 每个头只对**自身人格的平稳回报** \(R_i^t=\sum_k \gamma^k r_{i}^{t+k}\) 做 GAE 回归，与 \(\tilde w\) 如何变化无关；
  - 策略更新使用**混合优势** \(\bar A_t=\sum_i \tilde w_i^t A_i^t\)，\(A_i^t=R_i^t-V_\phi^i(s_t)\)，代入标准 PPO 裁剪替代目标；
  - 价值损失 \(L_V(\phi)=\sum_i \mathbb{E}_t[(V_\phi^i(s_t)-R_i^t)^2]\)。

### 算法流程（Algorithm 1，文字版）
1. 用 \(\pi_\theta\) 采样 rollout；
2. 对每步计算 \(w_i^t\)、归一化得 \(\tilde w_i^t\)，并计算各人格奖励 \(r_i^t\)；
3. 用各自价值头与 GAE 计算每人格回报 \(R_i^t\) 与优势 \(A_i^t\)；
4. 混合优势 \(\bar A_t\leftarrow\sum_i \tilde w_i^t A_i^t\)；
5. K 个 epoch 内：用 PPO 裁剪目标 + 熵 bonus 更新 \(\theta\)；用逐头 MSE 更新 \(\phi\)。

## 3. 实验设计

- **环境 / Benchmark**：Crafter（Hafner 2022），标准 1M 环境步训练预算；22 个成就分为 collection / crafting / combat / survival 四类，与四人格对应；成就大多位于顺序科技树上（如 Place Table 是木级工具的公共前置），深层成就低成功率反映整条前置链。
- **实现**：PyTorch 实现 PPO；所有条件共享编码器、优化器（Adam）、rollout 长度、batch size、GAE 系数、PPO clip、熵 bonus，仅奖励信号、混合锐度、评论家头数不同。
- **对比条件（共 9 组）**：
  - RIDGE 默认（\(\alpha=1.0\)，4 个价值头）；
  - 4 个单头固定人格基线（Explorer / Survivor / Craftsman / Warrior）；
  - RIDGE 架构上的锐度消融 \(\alpha\in\{0.0,0.5,1.5,2.0\}\)，其中 \(\alpha=0.0\) 等价于四奖励等权线性组合，即“无状态条件化”消融，也对应线性标量化 MORL 的均匀权重情形。
- **外部参照**：与成就蒸馏（Moon et al. 2023）做概念性对比而非同轴对比——Moon 用 IMPALA ResNet 编码器，报告 15.60%（4M 参数）、21.79%（9M 参数）、17.07%（1M 参数变体），而 Hafner 的简单 CNN PPO 基线约 4%；RIDGE 自报 6.30% Hafner-canonical 分数，作者明确声明“不是该指标上的竞争性结果”。
- **统计口径**：每条件 n=3 seeds，成就率为最后 100 个 episode 的均值，图中阴影为 min/max 带。

- **跨分支覆盖**：所有条件都能到 Place Table（RIDGE 0.75、Craftsman 0.90、Warrior 0.88），但之后专家分叉——Craftsman 木镐 0.70 / 木剑 0.16，Warrior 木剑 0.79 / 木镐 0.12；**RIDGE 是唯一在两条分支上都有可观成功率的条件**（木镐 0.32、木剑 0.26），即单个训练好的智能体同时跨过木材层制作/战斗分叉。
