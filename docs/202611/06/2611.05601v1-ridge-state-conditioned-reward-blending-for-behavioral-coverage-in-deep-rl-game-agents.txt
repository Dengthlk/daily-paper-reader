# RIDGE: State-Conditioned Reward Blending for Behavioral Coverage in Deep RL Game Agents 

AL Muqshith Mohammed Shifan, Kevin Christopher Chua, Ali Neshati, Loutfouz Zaman, Cristiano Politowski 

Ontario Tech University 

{mohamealmusqi.mohamedshifan, kevinchristopher.chua}@ontariotechu.net {ali.neshati, loutfouz.zaman, cristiano.politowski}@ontariotechu.ca 

Abstract —A deep RL agent trained on a fixed persona reward plays one way: an Explorer keeps exploring while starving, a Survivor hoards on an empty map. Since each persona fixes its own reward, automated playtesting trains N agents for N

styles. Changing reward composition mid-episode runs into the switching-stability dilemma: Proximal Policy Optimization (PPO) degrades under non-stationary rewards. We present RIDGE ,a single-agent architecture that sidesteps the dilemma with two design choices: a state-conditioned blender that computes softmax-normalized sigmoid weights from slow-moving state variables, and a multi-head critic that trains one value head per persona on its own stationary signal. On Crafter with four personas, one R IDGE agent acquires both branches of the wood-tier crafting/combat split that no fixed-persona baseline solves jointly, and a sharpness ablation confirms state-conditioning drives the gain. We position these results as demonstrations of the blending mechanism’s dynamics across n = 3 seeds per condition; larger multi-seed sweeps remain future work. 

Index Terms —reinforcement learning, automated playtesting, procedural personas, reward shaping, PPO, Crafter 

I. I NTRODUCTION 

A starving player stops exploring to find food and then resumes once he is satiated. Human players do this naturally, and automated playtesters need to cover the same kind of within-episode shift, yet a deep RL agent trained on a fixed reward plays one way: an Explorer keeps exploring while starving, a Survivor hoards on an empty map. Game devel-opers work around this by defining procedural personas [1]: they pair each agent with a different reward composition, train one agent per persona, then take the union of behaviors at deployment. This scales linearly ( N personas cost N training runs and N× environment steps), but it also misses the within-episode dynamics that motivated the personas in the first place. In a Crafter-like open-world survival setting [2], an Explorer rewards map novelty, a Survivor health and hunger maintenance, a Craftsman tool-building, and a Warrior combat engagement, while a real player moves between all four within a single playthrough. The natural fix is to change reward composition during 

an episode, conditioned on agent state. Prior work avoids this because in-episode reward shifts break Proximal Pol-icy Optimization (PPO). Li [3] formalizes the problem as the switching-stability dilemma : PPO’s value function needs a quasi-stationary signal, so hard reward switches break convergence. He documents the effect in Large Language Model (LLM)-guided satellite scheduling, where near-constant weights outperform carefully tuned dynamic ones. Moalla et al. [4] reach the same conclusion from the representation side: PPO under non-stationarity loses feature rank and ca-pacity. An in-episode persona blender therefore has to shift rewards in a way that PPO can still handle. RIDGE (Reactive Inter-persona Dynamic Goal Engine) ad-dresses this gap with two design choices. (i) Smooth blending 

computes softmax-normalized sigmoid weights from slow-moving state variables (health, hunger, crafting progress, enemy proximity), so the effective reward varies smoothly between nearby states. (ii) A multi-head critic keeps one value head per persona. Each head trains on a stationary per-persona reward signal, regardless of how the blender weights evolve, which isolates value-function learning from the shifting mixture. This paper makes three contributions. (1) A state-conditioned blender coupled with a multi-head critic, designed to address the switching-stability dilemma in persona-based playtesting. (2) Preliminary Crafter evidence that one R IDGE 

agent acquires both branches of the wood-tier crafting/combat split that no fixed-persona baseline solves jointly, with n = 3 

seeds per condition. (3) A sharpness ablation showing that state-conditioning, not the persona set alone, drives the result, plus a direct comparison to achievement distillation [5] in Sec-tion VI: complementary mechanisms, different deliverables. II. R ELATED WORK 

Personas for playtesting. Holmgård et al. [1] introduced procedural personas, and later work [6] extended them. Both encode play styles as utility functions with fixed weights. Ariyurek et al. [6] argue against static personas and pro-pose a developing persona whose goals progress over time, together with an Alternative Path Finder that adjusts the PPO reward for trajectory diversity. Their changes act between episodes; R IDGE ’s act within an episode and condition on state. Curiosity-driven coverage agents [7] go after broader behavioral reach through intrinsic exploration bonuses, not persona blending. The closest contemporary works supply the blending signal externally. MultiGAIL [8] trains one agent to imitate multiple persona policies from human demonstrations, conditioned on an external blending coefficient set at inference time. Cilan and Özgövde [9] condition a single PPO policy arXiv:2611.05601v1 [cs.LG] 3 Nov 2026 on an external behavior-target vector. R IDGE computes the blending signal internally from game state, so the mixture reflects behavioral need rather than user prior. 

Adaptive reward weighting and multi-head critics. The closest architectural precedent is HDPG [10], a multi-head critic for bipedal locomotion where each head estimates a single reward component and a weight schedule (training progress) combines them. R IDGE uses the same multi-head pattern, but with semantically interpretable persona heads and weights that vary with state within each episode . Com-pared to standard Multi-Objective Reinforcement Learning (MORL) [11], [12], which treats scalarization weights as ex-ternal configuration, R IDGE performs state-conditioned scalar-ization with internal weights. This also separates R IDGE from hard intra-episode switching, whose abrupt transitions trigger Li’s dilemma. 

PPO non-stationarity. Li [3] formalizes the switching-stability dilemma: near-constant reward weights ( 342 Mbps) outperform tuned dynamic weights ( 103 Mbps) because PPO requires a quasi-stationary signal for value-function conver-gence. Moalla et al. [4] address the representation-side coun-terpart with Proximal Feature Optimization. RIDGE ’s two design choices target the value-function side of the same phe-nomenon: smooth blending keeps the aggregate reward quasi-stationary, and the multi-head critic isolates each persona’s value estimate from the shifting mixture. 

Crafter benchmark methods. Several methods target Crafter [2] directly, including achievement distillation [5]. Two caveats matter when comparing absolute scores. Moon et al. [5] report PPO baselines using an Importance-Weighted Actor-Learner Architecture (IMPALA) [13] ResNet encoder (4M parameters) reaching 15 .60% , far above the ∼ 4% PPO Hafner [2] reports under a simpler Convolutional Neural Net-work (CNN); Moon’s headline 21 .79% uses 9M parameters and a 1M-parameter variant scores 17 .07% , so the gain reflects both model scale and the contrastive auxiliary loss. These methods optimize raw achievement under Crafter’s default sparse reward. RIDGE instead prioritizes broad behavioral coverage within-episode, guided by designer-authored persona shaping. Section VI returns to Moon et al. directly. III. M ETHOD

Value-function stability (Fig. 3). RIDGE ’s value loss stays at ≈ 0.04 throughout training, comparable to Explorer-only and below Craftsman and Warrior. Survivor-only sits an order of magnitude higher (0.3–0.5), because its dense action-independent vital-shaping reward yields returns the single value head struggles to fit. With four per-persona heads each seeing a stationary signal, R IDGE ’s value-loss trajectory tracks the most stable specialist rather than degrading toward the non-stationary aggregate, which is direct evidence for the multi-head critic design choice. VI. D ISCUSSION 

Relationship to achievement distillation [5]. The canon-ical Crafter comparator at 1M steps is Moon et al. [5], who reach 21 .79% Hafner-canonical score with 9M parameters via contrastive auxiliary losses on the encoder. RIDGE is not on this axis. We report a 6.30% Hafner-canonical score for reproducibility, not as a competitive benchmark on this metric. Moon optimizes raw achievement under Crafter’s de-fault sparse reward, modifying what the agent knows ; R IDGE 

optimizes behavioral coverage under designer-authored per-sona shaping, modifying what the agent wants . For automated playtesting, an aggregate achievement score from an agent locked to one play style provides less value to a designer than a coverage profile across styles, which is what the wood-tier split demonstrates. The two mechanisms are independent in principle and complementary in practice: contrastive losses on a R IDGE -blended reward, or R IDGE blending on a distilled encoder, are both unexplored. VII. C ONCLUSION 

RIDGE combines a smooth state-conditioned blend over persona rewards with a critic carrying one value head per persona, letting a single PPO agent shift between play styles within an episode without breaking value-function learning. In Crafter, one R IDGE agent reaches both the Wood Pickaxe and Sword, a split no fixed-persona baseline solves, and a sharpness ablation confirms state-conditioning, not the persona set alone, drives the gain. Three extensions would tighten these claims further. While we now report n = 3 seeds across all conditions, additional seeds would replace the current min/max bands with confi-dence intervals. A hard-switch run ( α → ∞ ) would put Li’s dilemma [3] under direct test; our α = 2 .0 approaches but does not reach it. Finally, a single-head version of R IDGE would separate the multi-head critic’s contribution from the smooth blend’s contribution. While Crafter is currently the only tested environment, these initial results demonstrate R IDGE ’s poten-tial for training highly adaptable agents. REFERENCES
