## 摘要
带可验证奖励的离线强化学习（RLVR）在固定的采样回复池上训练，并且通常对每个回复的每个 token 都进行监督，尽管不同回复和 token 所提供的信息量并不相同。我们通过 KL 正则化 RLVR 的 Gibbs 最优策略来研究应监督哪些回复和 token，该策略是离线训练的目标，并用双向 KL 散度衡量策略与该目标之间的失配。在参考策略处，该失配可精确因子分解，并将两种结果区分开：正确回复主要通过前向项贡献，且集中在其低概率 token 上；错误回复则通过反向项贡献，且集中在策略经常生成的回复及其高概率 token 上。基于这一分析，我们提出 GIST（Gibbs 目标引导的分层数据选择），一种两级选择方法，利用训练前可获得的信号来近似这些原则。GIST 使用采样温度来选择同策略的正确回复以及接近策略众数的错误回复，并使用初始策略的 token 概率仅监督失配所在的 token。在两个离线训练目标上应用时，GIST 在两种目标下均提升了所有三个模型在 GSM8K、MATH-500 和 MBPP 上的平均准确率。在 Qwen3-0.6B/GSM8K 上的受控比较中，它优于七个从相同候选中进行选择的选择基线，同时相比在同一提示的所有候选上训练，监督的 token 数少 66.6%。

## Abstract
Offline reinforcement learning with verifiable rewards (RLVR) trains on a fixed pool of sampled responses and typically supervises every token of every response, although responses and tokens are not equally informative. We study which ones to supervise through the Gibbs-optimal policy of KL-regularized RLVR, which offline training targets, and measure the mismatch between a policy and this target with a bidirectional KL divergence. At the reference policy, this mismatch factorizes exactly and separates the two outcomes: correct responses contribute mainly through the forward term, concentrated on their low-probability tokens, and incorrect responses through the reverse term, concentrated on the responses the policy generates often and on their high-probability tokens. Based on this analysis, we propose GIST (Gibbs-Targeted Hierarchical Data Selection), a two-level selection method that approximates these principles with signals available before training. GIST uses the sampling temperature to select correct responses on-policy and incorrect responses near the policy's mode, and it uses the initial policy's token probabilities to supervise only the tokens where the mismatch lies. Applied to two offline training objectives, GIST raises the average accuracy over GSM8K, MATH-500, and MBPP for all three models under both objectives. In a controlled comparison on Qwen3-0.6B/GSM8K, it outperforms seven selection baselines that choose from the same candidates while supervising 66.6% fewer tokens than training on all candidates of the same prompts.

## 1. 核心问题与研究背景

- **研究场景**：带可验证奖励的离线强化学习（Offline RLVR）在一个固定的采样回复池上训练语言模型，回复的正确性由自动验证器（答案匹配 / 单元测试）给出二元奖励。
- **核心痛点**：现有做法（拒绝采样、奖励加权目标如 BOLT、rollout 子采样、熵/概率 token 选择）普遍**对保留下来的每条回复的每个 token 等权监督**，但回复与 token 的信息量差异巨大——高温度采样中的低概率 token 可能是噪声，也可能是被策略低估的有效推理步骤；低温度采样的失败则揭示策略众数附近的系统性错误。
- **关键问题**：在离线 RLVR 中，**应当保留哪些回复、监督它们的哪些 token**？现有方法只解决其中一层（要么选回复、要么选 token），缺少将"结果标签"与"采样方式"统一起来的分层选择原则。
- **研究视角**：作者从 KL 正则化 RLVR 的 **Gibbs 最优策略**（离线训练真正拟合的目标）出发，用**双向 KL 散度**度量策略与该目标的失配，并据此推导选择准则。

## 2. 方法论

### 2.1 核心思想

- 离线训练拟合的目标是 Gibbs 分布：π\*(y|x) = π_ref(y|x)·e^{r(x,y)/β} / Z(x)，其中 r∈{0,1}，π_ref = π₀（初始策略）。
- 用**双向 KL** D^λ(p,q) = KL(p‖q) + λ·KL(q‖p) 刻画策略 q 与目标 p 的失配：前向项衡量"策略低估目标行为"（覆盖不足），反向项对应 RLVR 目标差距（过度拟合错误）。
- 引入 **KL 曲率得分** U^λ_y = (p_y − q_y)²·(1/q_y + λ/p_y)，用局部曲率加权概率差，使小概率处的同等差距被放大。

### 2.2 关键理论结果

- **定理 3.1（曲率界）**：在密度比有界条件下，c⁻·U^λ ≤ D^λ ≤ c⁺·U^λ；当策略趋近目标时 D^λ = ½U^λ + o(U^λ)，即曲率得分在目标附近二阶精确。
- **推论 3.2（预算选择保证）**：按 U^λ_y 选出的 B 个回复，可捕获最优子集失配的常数比例 (c⁻/c⁺)，类似 coreset 保证。
- **推论 3.3（信息性回复）**：正确且被低估的回复 → 前向项主导（U ∼ p²/q）；错误且被高估的回复 → 反向项主导（U ∼ λq²/p）。
- **命题 3.4（参考策略处精确分解）**：q = π_ref 时 K^λ_y = q_y·h_λ(κ_r)，正确回复 κ₁ ≈ 1/P(x) > 1（被低估），错误回复 κ₀ ≈ e^{−1/β}/P(x) < 1（被高估）；**类内贡献正比于 q_y**，即高频生成的错误回复贡献最大。
- **推论 3.6（信息性 token）**：正确回复中**低概率 token**（q_t ≪ p_t）承载前向失配；错误回复中**高概率 token**（q_t ≫ p_t）承载反向失配。
- **命题 3.7（token 级分解）**：π_θ = π_ref 时 K^λ_t = q_t·h_λ(ρ_t)，且 ρ_t ≤ 1/q_t——大的软价值增益必须伴随低 q_t。
- **Remark 3.8**：类内排序、ρ_t ≤ 1/q_t 的界、软价值符号对任意 β > 0 成立；**只有两类之间的平衡依赖 β 与 λ**，因此 GIST 用各类保留数量来设定类间平衡。

> 上述分析归纳为四条选择原则（表 1）：正确→前向/欠代表→低概率 token；错误→反向/过代表→高概率 token。

### 2.3 GIST 算法流程（两级选择，训练前一次性完成）

- **Step 1 采样**：对每个 prompt，用初始策略 π₀ 分别以 τ_h = 1.0 与 τ_l = 0.3 各生成 N_h = N_l = 16 条回复（无 top-p/top-k 截断）。
- **Step 2 回复级"温度配对"**：
  - 正确回复取自**同策略池** Y⁺(x) = {y ∈ Y_h : r = 1}；
  - 错误回复取自**近众数池** Y⁻(x) = {y ∈ Y_l : r = 0}；
  - 仅保留同时满足 |Y⁺| ≥ B⁺ 且 |Y⁻| ≥ B⁻ 的 prompt（B⁺ = B⁻ = 4），每类均匀无放回抽 4 条。
- **Step 3 token 级掩码**：用冻结的 π₀ 计算 q_t = π₀(y_t | x, y_{<t})，以该回复内（排除 EOS）的均值 q̄ 为阈值：
  - 正确回复：m⁺_t = 1[q_t < q̄]（保留低概率 token）；
  - 错误回复：m⁻_t = 1[q_t > q̄]（保留高概率 token）；
  - 掩码训练前计算一次，训练全程固定。
- **Step 4 与离线目标结合**：可与任意加权回复的离线目标搭配。作者用 **BOLT**（权重 e^{r/β}，在 32 条候选池上归一化使均值为 1，选择后不重归一化，β = 0.1）与 **SFT**（单位权重）。损失为掩码位置上 token 负对数似然的加权平均，未选中位置保留在上下文中但不计损失。
