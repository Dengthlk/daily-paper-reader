## 摘要
OPSD通过特权信息反馈为智能体强化学习提供密集监督。然而，现有特权信息往往缺乏显式的任务进展规划，而师生对数概率差距反映的是模型偏好变化，而非真实任务进展。为解决这些局限，我们提出子目标引导的图正则化OPSD（SGR-OPSD），该框架将子目标监督与交互衍生证据相结合，用于轮次级信用分配。具体而言，SGR-OPSD利用LLM生成的子目标计划提供密集的动作级指导，并通过受约束的KL正则化目标将其转化为优势权重。为使信用建立在观测结果之上，我们构建子目标进展图，从采样转移频率中估计经验回报。该图将经验动作回报与状态平均值进行比较，以导出偏好并校准教师的信用权重。在ALFWorld、WebShop和Search-QA上，跨两种模型规模（Qwen2.5-3B和7B）评估时，SGR-OPSD始终优于GRPO和强自蒸馏基线，相较GRPO将成功率最高提升7.4个百分点，并在Qwen2.5-7B上于ALFWorld达到85.8%。消融研究证实，子目标指导与基于图的权重校准是这些性能提升的关键。

## Abstract
OPSD provides dense supervision for agentic reinforcement learning through privileged information feedback. However, existing privileged information often lacks explicit task-progression planning, while teacher-student log-probability gaps reflect shifts in model preference rather than true task progress. To address these limitations, we propose Subgoal-Guided Graph-Regularized OPSD (SGR-OPSD), a framework that combines subgoal supervision with interaction-derived evidence for turn-level credit assignment. Specifically, SGR-OPSD uses LLM-generated subgoal plans to provide dense action-level guidance, converting them into advantage weights via a constrained, KL-regularized objective. To ground credit in observed outcomes, we construct a Subgoal Progress Graph that estimates empirical returns from sampled transition frequencies. The graph compares empirical action returns against the state average to derive preferences that calibrate the teacher's credit weights. Evaluated on ALFWorld, WebShop, and Search-QA across two model scales (Qwen2.5-3B and 7B), SGR-OPSD consistently outperforms GRPO and strong self-distillation baselines, improving success rates over GRPO by up to 7.4 percentage points and reaching 85.8% on ALFWorld with Qwen2.5-7B. Ablation studies confirm that subgoal guidance and graph-based weight calibration are key to these performance gains.

## 1. 核心问题与研究动机

- **背景**：LLM 智能体需要通过多轮交互完成复杂任务（如 ALFWorld 家居操作、WebShop 购物、Search-QA 检索问答），强化学习训练需要细粒度的中间决策监督，而仅靠稀疏的结果奖励（如 GRPO）无法区分各轮次的贡献。
- **OPSD 的思路与局限**：On-Policy Self-Distillation（OPSD）用特权信息（privileged information）条件化教师模型，对学生在轨采样的动作打分，从而提供密集监督。但论文指出两个关键缺口：
  - **缺乏显式任务进展规划**：现有特权信息（如 trajectory-derived skills、参考答案）往往只给通用工作流规则，未针对当前任务给出有序的子目标与前置条件。
  - **师生对数概率差 ≠ 真实任务进展**：该差距只反映模型偏好在特权信息下的偏移，可能错误地偏向偏离成功延续的动作，缺乏与真实交互结果的 grounding。
- **核心主张**：有效的回合级信用分配需要同时具备（a）任务特定的规划信息，（b）将教师影响锚定在执行证据上的校准机制。

## 2. 方法论

### 2.1 整体框架

- **SGR-OPSD** 由两条支路构成：子目标引导的教师信用权重（teacher reference weights） + 子目标进展图（Subgoal Progress Graph）的经验证据校准，最终重分配 GRPO 优势。
- 训练时使用子目标计划与图；**推理时学生不需要计划或图**。

### 2.2 子目标引导的信用权重

- **子目标计划生成**：用 DeepSeek-V3.1 仅根据任务描述 x 生成固定、有序的计划 z(x)（2–8 个子目标，含 goal 与 precondition），只注入教师上下文 h^T，学生使用普通上下文 h^S。
- **动作级证据**：对执行动作的 token 位置求和师生对数概率差：
  - d_{i,t} = Σ_{k∈A_{i,t}} (log π^T_{i,t,k} − log π^S_{i,t,k})
- **约束 KL 加权**：在权重区间 [1−ε, 1+ε]、零优势轮权重固定为 1、每条轨迹 token 加权预算 Σ_t p_{i,t} w_{i,t} = 1 的约束下，最大化带符号的教师支持项 U(w) = Σ p_{i,t} s_{i,t} d_{i,t} w_{i,t} 减去 KL 正则 T·D_p(w‖1)，其中 s_{i,t} = sign(A_{i,t})。
- **闭式解**：w^ref_{i,t} = clip(exp((s_{i,t} d_{i,t} − ν_i)/T), 1−ε, 1+ε)，ν_i 由二分法满足轨迹预算。
- **直觉**：正优势动作若教师支持强则放大权重，负优势动作若教师支持强则减小惩罚。

### 2.3 子目标进展图

- **构图**：将同一任务 8 条 rollout 中匹配的状态合并为图节点，用转移计数估计经验值：
  - Q̂(v,a) = Ê[r + γI·V̂(v′) | v,a]，V̂(v) = Σ_a π̂(a|v) Q̂(v,a)
- **相对信号**：δ_{i,t} = Q̂(v_{i,t}, a_{i,t}) − V̂(v_{i,t})，裁剪为 g_{i,t} ∈ [−b_G, b_G]，正值表示高于状态平均经验回报。
- **动作比较**：在匹配计划、学生上下文与剩余预算的访问上聚合，ḡ(a) = H_a^⊤ g；若 ḡ(a) > ḡ(b) 则 a ≻ b，形成偏好对集合 E。

### 2.4 联合信用校准与策略优化

- **权重参数化**：w_{i,t}(c) = 1 + s_{i,t} c_{i,t}，c 为信用修正量。
- **联合目标**：min_c T_G·D_p(w(c)‖w^ref) + β·R_G(c)，其中 R_G(c) = ½ Σ_{e∈E} ρ_e [μ − b_e^⊤ c]_+² 为 hinge 惩罚，鼓励图偏好动作获得更大修正；约束保持 token 预算、权重边界与零优势轮不变。
- **求解**：float64 Nesterov 加速投影梯度下降，带单调重启与收敛校验；无合格比较的轨迹严格保留教师参考权重。
- **最终优势**：Ã_{i,t} = A_{i,t}·w*_{i,t}，同一轮所有有效 token（含推理 token）共享；策略损失为 L_SGR = L_policy(θ; sg(Ã)) + λ_KL L_KL(θ)。

## 7. 贡献与启示

- **方法层面**：把 OPSD 的“特权信息”从通用工作流规则升级为“任务特定子目标计划 + 前置条件”，并首次系统性地指出师生对数概率差缺乏任务进展 grounding 这一结构性缺陷。
- **机制层面**：提出“教师参考权重（闭式、带预算约束的 KL 加权）+ 图经验偏好（hinge 校准）”的两级信用分配框架，且推理时零额外开销（学生不需要计划或图），工程可用性较好。
- **实证层面**：在操作、购物、检索三类智能体任务、两种模型规模上给出一致的增益，并通过独立 continuation 验证、校准分析与 case study 对机制而非仅对结果做了解释。
- **启示**：密集信用分配的关键不只是“更多监督信号”，而是“信号之间的相互校验”；将离线生成的任务计划与在轨经验图结合，是一种低成本、可插拔的折中方案。

## 8. 局限性与需注意之处

- **协议不完全统一**：
  - SearchQA 主表与学习曲线使用不同的 checkpoint 选择协议（主结果固定 update-150，曲线另用验证选择），跨表比较需谨慎。
  - ALFWorld/WebShop 使用训练时验证选 checkpoint，而 SearchQA 未采用同一协议，可能影响方法间相对排序的严格可比性。
- **算力报告不完整**：仅报告 8×A100 与 150 次更新，缺少总 GPU 小时、墙钟时间与 DeepSeek-V3.1 离线生成计划的成本量化，复现成本不易估计。
- **外部依赖**：子目标计划由 DeepSeek-V3.1 离线生成，计划质量受该模型能力与提示设计影响；论文未报告计划质量的下界分析或人工校验比例。
- **收益的规模/环境依赖**：w/o Graph 在 ALFWorld 3B 上几乎持平、在 7B 上大幅下降，说明图校准收益随模型能力增强而放大；对小模型或极短回合任务（SearchQA 4 轮）增益有限。
- **覆盖稀疏**：仅约 3.95% 轮次参与图比较，方法主体仍依赖教师支路，图校准的独立贡献边界尚需更大规模验证。
- **单一计划源与单一图构建策略**：未比较多计划采样、不同状态抽象粒度或跨任务共享图的方案，泛化性与可扩展性仍待检验。

SGR-OPSD 针对“回合级信用分配”这一 LLM 智能体 RL 的核心痛点，提出了问题定位清晰、机制可解释、推理零开销的两级校准方案。论文在三个异构环境和两种模型规模上给出一致的性能提升，并通过独立进展验证与校准分析对“为什么有效”提供了超出结果表的证据，实验矩阵与消融设计总体严谨。其主要不足在于评测协议的部分不统一、算力与计划生成成本报告不完整，以及图校准触发稀疏导致贡献边界不够清晰。总体而言，这是一篇方法动机扎实、工程可行性较强、实证较充分的工作，适合作为 OPSD/GRPO 类智能体训练流水线的即插即用改进参考。
