ABSTRACT 

Skill memories encode past experiences as textual prompts to improve reinforce-ment learning (RL) for self-evolving agents. Complementing RL, On-Policy Self-Distillation(OPSD) provides dense, fine-grained supervision to internalize knowl-edge from skill-guided trajectories and accelerate policy learning. However, self-generated memories often contain noisy supervision and functionally entangled, redundant, or conflicting knowledge, making direct distillation difficult. Under limited training budgets, these issues can hinder knowledge internalization and even degrade performance. To address this problem, we propose MDSKILL, a multi-view distillation approach for skill memory internalization. MDSKILL or-ganizes skill memories into three complementary functional views—state ground-ing, action planning, and execution control—and selects high-quality skills using dynamic metrics to construct view-specific and integrated reasoning branches. OPSD then transfers and consolidates complementary experiential knowledge across these branches into a shared policy, enabling efficient skill internaliza-tion and continuous agent self-evolution. We evaluate MDSKILL on three agent benchmarks against RL, skill-augmented, and self-distillation baselines that do not rely on stronger external teacher models. Without additional computational overhead, MDSKILL improves upon SOTA performance by up to 7.1% and 8.1% on ALFWorld and WebShop. Extensive ablations and evolution analyses further validate its effectiveness in knowledge internalization and policy improvement. The code is available at the https://anonymous.4open.science/r/MDSKILL-CF53. 

1 INTRODUCTION 

Agentic reinforcement learning (RL) has demonstrated strong performance on multi-turn interactive tasks (Shao et al., 2024; Yang et al., 2025; Dong et al., 2026; Feng et al., 2026). However, sparse and delayed rewards provide limited supervision for policy improvement. Skill memories offer a promising source of experiential knowledge: they summarize lessons from real interaction trajecto-ries and guide subsequent decisions through textual prompts (Shinn et al., 2023; Wang et al., 2023). Although external skill memories improve task success, agent self-evolution requires internalizing their experiential knowledge into model parameters to retain and apply acquired capabilities with-out explicit memory retrieval. On-Policy Self-Distillation (OPSD) distills skill-view trajectories into the skill-free branch, providing dense supervision for skill internalization and policy learning (Zhao et al., 2026; He et al., 2026a; Zhang et al., 2026a). Combining OPSD with RL enables more effective agent self-evolution and greater performance gains (Lu et al., 2026a; Tu et al., 2026a). OPSD uses high-quality reference responses to provide reliable teacher supervision (Zhao et al., 2026). In online agent self-evolution, however, the teacher branch relies on self-generated skill memories that may contain ineffective, harmful, or hallucinated strategies, potentially causing the skill-view branch to underperform its skill-free counterpart (Tu et al., 2026a). Consequently, direct distillation can propagate erroneous behaviors and provide inconsistent supervision for useful knowledge, hindering its internalization into model parameters. Motivated by these observations, we propose MDSKILL, a multi-view distillation framework for skill memory internalization. It uses dynamic value metrics to select skills with additional deci-sion value and organizes them into three complementary functional views: state grounding, action planning, and execution control. These views guide three view-specific branches and an integrated branch alongside a skill-free branch. By disentangling experience according to its decision func-tion, multi-view distillation reduces transfer interference and consolidates complementary knowl-edge into the shared policy. The skill-view and skill-free branches then co-evolve, generating better trajectories and skill memories that sustain agent self-evolution. Figure 1 summarizes MDSKILL’s framework, empirical results, and the intuition behind multi-view distillation. Across three agent benchmarks, MDSKILL outperforms RL, skill-augmented, and self-distillation baselines that do not rely on stronger external teacher models, improving upon SOTA performance by up to 7.1% and 8.1% on ALFWorld and WebShop without additional computational overhead. Extensive ablations and skill-evolution analyses support its effectiveness, while gains in both skill-2view and skill-free branches indicate successful knowledge internalization rather than continued reliance on external memories. Our main contributions are summarized as follows: • We observe and identify a key challenge in skill-guided agent self-evolution: noisy and functionally entangled skill memories can hinder knowledge internalization and degrade performance. • We propose MDSkill, a multi-view distillation framework that organizes skill memories into complementary decision views and transfers knowledge across skill-view and skill-free branches for more stable and effective experiential knowledge internalization. • Experiments on three agent benchmarks show that MDSKILL improves upon SOTA perfor-mance, with extensive ablations and skill-evolution analyses supporting its effectiveness.

3 ANALYSIS OF DISTILLATION DIRECTIONS 

We analyze four training variants to examine how distillation direction affects skill-memory inter-nalization: no distillation, forward distillation from the skill-view to the skill-free branch, reverse distillation in the opposite direction, and bidirectional distillation combining both. 

Distillation effectively internalizes externalized experience. Forward distillation propagates unreliable supervi-sion. Forward-only distillation performs substantially worse because the dense supervision signals from the skill-view branch are unreliable. Forward distillation exhibits instability and distri-butional misalignment. To investigate why forward distillation degrades performance, we follow (Li et al., 2026b) and analyze Top-K overlap and the absolute en-tropy gap in Figure 3. Forward distillation requires the skill-free branch to reproduce skill-conditioned prefer-ences without access to the underlying skill. Its low, volatile overlap and large, fluctuating entropy gap sug-gest persistent misalignment and unstable supervision, potentially introducing noisy policy updates. In con-trast, reverse distillation primarily corrects harmful skill influence and exhibits increasing overlap and a smaller, more stable entropy gap. 

Skill noise and knowledge entanglement hinder ef-fective transfer. Although forward distillation under-performs reverse distillation, it substantially outper-forms no distillation, indicating that skill-guided super-vision contains useful knowledge alongside unreliable signals. The challenge therefore lies not simply in a lack of valuable knowledge, but in transferring it effectively. Beyond skill noise, re-dundant or conflicting guidance from entangled decision functions can obscure useful signals and complicate internalization. These observations motivate dynamic value metrics to prioritize reli-able, beneficial skills and multi-view decomposition to separate complementary decision functions, improving supervision quality and reducing transfer interference.

Action planning. This view addresses what to do next given the information . Planning skills describe how to select actions, establish subgoals, and or-der operations toward task completion. They direct exploration toward alternative action sequences and reusable strategies for making progress. 

Execution control. This view addresses whether ongoing execution should continue or change . Con-trol skills focus on checking action preconditions, detecting ineffective behavior, verifying intermedi-ate outcomes, and recovering from errors. They guide the agent to reconsider a plan when observa-tions contradict its expectations, rather than repeat-edly following an unsuccessful course of action. 

Combined branch. This branch integrates knowl-edge from three skill views, allowing grounding, planning, and control to complement one another. It connects observation interpretation with action se-lection and execution monitoring, enabling the agent to adjust its plan as new evidence emerges. The re-sulting trajectories capture interactions among deci-sion functions and provide an integrated path along-side the view-specific branches. 5.1 EXPERIMENTAL SETUP 

Benchmarks Following the evaluation suite of SDAR (Lu et al., 2026a), we evaluate on three agent benchmarks. ALFW ORLD (Shridhar et al., 2020) tests household navigation and object ma-nipulation across six task families: Pick, Look, Clean, Heat, Cool, and Pick2. W EB SHOP (Yao et al., 2022) requires agents to find and purchase products satisfying natural-language requests; we use the established 128-task evaluation split. S EARCH -QA (Jin et al., 2025) evaluates search-augmented question answering across three single-hop and four multi-hop datasets. We report success rates on ALFWorld, task scores and success rates on WebShop, and answer accuracy on Search-QA.

5.2 MAIN RESULTS 

Overall Performance. Table 1 shows that MDSkill achieves the best overall success rates on both ALFWorld and WebShop across all three backbones. On ALFWorld, MDSkill outperforms the strongest baseline UCOB by 7.1%, 3.1%, and 2.3% with Qwen3-1.7B, Qwen2.5-3B, and Qwen2.5-7B, respectively. On WebShop, it improves the success rate by 8.1%, 3.2%, and 3.9%, while main-taining competitive task scores. MDSKILL also achieves competitive performance on Search-QA across model scales. Compared with interactive decision-making tasks, Search-QA depends more on retrieval quality, evidence comprehension, and answer synthesis, and less on recurring environ-ment states where reusable skills offer consistent guidance. 

Knowledge Internalization. The consistent gains on ALFWorld and WebShop demonstrate the value of internalizing skill memories from complementary decision perspectives. The gains are par-ticularly pronounced with the smaller Qwen3-1.7B model which has fewer task-relevant priors and reusable interaction patterns, with success rates increasing from 86.7% to 93.8% on ALFWorld and from 74.7% to 82.8% on WebShop. By organizing skill memories into complementary views and distilling successful behaviors into the shared policy, MDSkill mitigates the knowledge disadvan-tage of smaller models, while the improved policy produces stronger trajectories and higher-quality skills that further reinforce knowledge internalization and agent self-evolution. 8Step

Main Ablation on Distillation. Figure 6a compares success rates and skill-view advantage, de-fined as the success-rate difference between skill-view and skill-free branches; a sustained negative gap indicates that memories hinder the evolving policy. We ablate forward distillation, cross-view distillation, multi-view rollouts, and distillation. MDSKILL performs best on both benchmarks, with its advantage approaching zero without remaining strongly negative. Removing distillation causes the greatest degradation, while removing multi-view rollouts has the largest impact among vari-ants retaining distillation. The performance of variants retaining multi-view exploration and partial distillation supports the benefits of broader exploration and disentangled knowledge transfer. Cru-cially, removing forward distillation reduces performance, contrasting with the earlier advantage of reverse-only distillation and showing that skill internalization becomes beneficial within MDSKILL. Cross-view distillation provides further gains through complementary knowledge internalization. 

Distillation Stability Analysis. Figure 6b compares MDSKILL with w/o multi-view rollouts .Without multi-view rollouts, forward token overlap fails to improve and the absolute entropy gap fluctuates sharply, indicating persistent misalignment and unstable distillation. MDSKILL instead achieves higher overlap and a smaller, more stable entropy gap, supporting the benefits of disen-tangled skill guidance. Cross-view distillation exhibits the lowest entropy gap and highest overlap, suggesting that knowledge transfer across complementary views is easier to optimize. 

Dynamic Skill Evolution Analysis. Figure 6c tracks the mean advantage of top-K skills from each generation cohort. In MDSKILL, high-advantage regions concentrate near the diagonal: new skills address current knowledge gaps, while older skills lose their advantage as their knowledge is internalized. In contrast, UCOB shows weaker diagonal concentration, indicating continued re-9liance on earlier skills. Figure 6d examines skills with substantial advantage ( > 0.6) across 4 lev-els of generality. MDSKILL shifts from instance-specific knowledge toward cross-task skills and meta-strategies, reducing the final instance-specific share to 26% , compared with 42% for UCOB. Although UCOB retains high-advantage skills, this reflects dependence on external memories rather than effective internalization. Together, MDSKILL shows healthy self-evolution, where new skills fill knowledge gaps, internalization reduces their marginal value, and skill evolution shifts toward new and more general knowledge. Additional ablations and analyses are provided in Appendix C. 

6 CONCLUSION 

We identify a key obstacle to skill-guided agent self-evolution: noisy and functionally entangled skill memories can provide unstable supervision, hindering knowledge internalization. We propose MDSKILL, a multi-view framework that dynamically selects useful skills, organizes them into com-plementary functional views, and explores both view-specific and integrated solutions. Outcome-based teacher–student grouping then supports forward, reverse, and cross-view distillation, enabling complementary knowledge to be reliably consolidated into the shared policy. Experiments on three agent benchmarks demonstrate SOTA performance, while ablations and evolution analyses verify more stable distillation and healthier skill evolution. Overall, MDSKILL establishes a self-evolution cycle in which multi-view skill knowledge improves the policy, and the evolving policy continually generates and internalizes better skill memories.

A.1 SKILL MEMORIES FOR LANGUAGE AGENTS 

Retrieval-augmented generation established a general paradigm for conditioning language models on external, non-parametric knowledge (Lewis et al., 2020). Language agents extend this paradigm from factual documents to interaction experience: Reflexion (Shinn et al., 2023) stores verbal feed-back from previous attempts, while Voyager (Wang et al., 2023) accumulates executable programs as reusable skills. Recent work further enables agents to construct, select, curate, evolve, or inter-nalize their own skill memories (Xia et al., 2026; Mi et al., 2026; Tu et al., 2026b; Ouyang et al., 2026; Zhang et al., 2026b; Lu et al., 2026b; He et al., 2026b; Lin et al., 2026; Zhang et al., 2026d; Shi et al., 2026; Tu et al., 2026a). These methods progress from retrieval-time skill augmentation toward evolving external repositories and policy-level knowledge internalization. However, self-generated skills may be noisy, redundant, or functionally entangled; MDSKILL addresses these limitations through dynamic skill selection and multi-view distillation. A.2 AGENTIC REINFORCEMENT LEARNING 

Proximal Policy Optimization (PPO) (Schulman et al., 2017) stabilizes policy learning through clipped updates, while GRPO (Shao et al., 2024) replaces the learned value function with relative rewards among grouped rollouts. Building on these foundations, recent agentic RL methods extend policy optimization to multi-turn environments involving reasoning, search, tool use, and environ-ment interaction (Wang et al., 2025; Wei et al., 2025; Feng et al., 2026; Zhu et al., 2026; Li et al., 2026a;c). These methods enable agents to improve from interaction outcomes, but their supervision remains largely dependent on sparse and delayed rewards. MDSKILL adopts GiGPO (Feng et al., 2026) as its RL backbone because its combination of episode- and step-level optimization is well suited to long-horizon, multi-turn agent interactions. A.3 ON-P OLICY SELF -D ISTILLATION 

On-policy distillation (OPD) provides dense teacher supervision on student-generated rollouts, reducing off-policy distribution mismatch (Agarwal et al., 2024). On-Policy Self-Distillation (OPSD) (Zhao et al., 2026) further uses the same policy as teacher and student under different contexts, with privileged information provided only to the teacher. This supplies dense token-level supervision alongside sparse RL rewards without requiring a separate teacher model. Recent work combines OPSD with agentic RL through skill-conditioned contexts, adaptive supervision, step-level transfer, and bidirectional correction (Yang et al., 2026; Wang et al., 2026; Lu et al., 2026a; Zhang et al., 2026c; Tu et al., 2026a). However, its effectiveness depends on the reliability of re-trieved skills. MDSKILL addresses this issue by decomposing skill knowledge into complementary views and performing outcome-guided multi-view distillation.

B.2 DISTILLATION .We use turn-level, response-scoped Top-K distillation with Ktok = 32 . For each anchor, we retain at most two teacher–student pairs independently for each of forward, reverse, and cross-view distil-lation. All three types share the same objective with λMD = 0 .2. We set the token-level confidence-gate coefficient to 5.0 and assign action tokens a distillation weight of 2.0. We use the strict gate for Qwen3-1.7B and the relaxed gate for Qwen2.5-3B-Instruct and Qwen2.5-7B-Instruct. Appendix D discusses the effect of gate selection across model scales. B.3 RETRIEVAL .We organize skill memories into three functional banks corresponding to state grounding, action planning, and execution control. At each encountered anchor state, we first retrieve the 10 most relevant candidates from each bank using the all-MiniLM-L6-v2 sentence transformer, with a relevance threshold of 0.4. For each candidate, we independently draw Thompson samples from its Reliability and Advantage posteriors and rank candidates by their equally weighted sum. Each view-specific branch selects the top three skills from its corresponding bank, whereas the combined branch selects the highest-ranked skill from each bank. Both posteriors are initialized with uniform 14 Beta(1 , 1) priors and use a temporal-decay half-life of 20 training steps. Within each functional bank, we further distinguish task-level and state-level memories following UCOB (Tu et al., 2026a).

D DISCUSSION ON DISTILLATION GATE 

Figure 8 compares the strict and relaxed distillation gates across different model scales. For Qwen2.5-3B, the relaxed gate achieves consistently higher success rates through most of training, and the 7B model exhibits the same trend. In contrast, Qwen3-1.7B benefits more from the strict gate, particularly during the later training stages. This scale-dependent reversal suggests that the gate reflects the reliability required of skill-view su-pervision. Smaller models possess less task knowledge and tend to generate lower-quality skills, making skill-view trajectories more likely to provide misleading supervision. The strict gate permits forward and cross-view distillation only when all skill-free trajectories fail, filtering ambiguous com-parisons and providing stronger evidence of skill-induced knowledge gain. Larger models generate and utilize more reliable skills; consequently, the relaxed gate can admit more informative teacher– student pairs and enlarge the effective distillation space without introducing excessive noise. Thus, strict filtering is preferable when skill-view supervision is less reliable, whereas relaxed filtering better exploits the stronger supervision available at larger model scales. 16 E ANALYSIS OF MULTI -V IEW DISTILLATION

F IMPLEMENTATION OF FUNCTIONAL SKILL REFLECTION 

MDSKILL uses view-specific reflection prompts to generate functionally distinct skills. Figure 9 summarizes their differences and presents examples from the trained ALFWorld skill banks. Shared prompt components are omitted for readability, with complete templates provided in our code. 

Functional Skill Generation and Verification. For each trajectory comparison, MDSKILL gen-erates grounding, planning, and control candidates using their respective prompts. Grounding cap-tures task-relevant states, planning extracts action or subgoal ordering, and control focuses on ex-ecution monitoring and recovery. Each candidate then undergoes functional-attribution verification and is admitted to its intended bank only when the predicted category matches the requested view. This generate–then–verify process reduces cross-view contamination and preserves functional sep-aration. 

ALFWorld Example. Figure 9 presents three skills generated from an ALFWorld episode requir-ing a kettle to be cleaned and placed in a stoveburner. The grounding skill identifies uncertainty about the kettle’s location and cleanliness; the planning skill orders the locating, cleaning, and placement subgoals; and the control skill checks the object location and cleaning preconditions. The example shows how the same trajectory evidence yields distinct, functionally targeted skills rather than paraphrases of a single lesson. 18 Shared prompt components. Each prompt receives the task category, task description, trajectory outcome, a successful reference trajectory when available, and the trajectory being evaluated. It returns valid JSON containing {task success, task category, title, principle, when to apply, evidence }.

State-Grounding Reflection View-specific instructions. 

Write one high-level grounding skill that helps a future agent determine the current world state before acting. 

Think about: 

1. Which room, receptacle, visible object, inventory item, or object state mattered? 2. What task-relevant fact was unknown or misinterpreted? 3. What observation, navigation, or inspection action exposed that fact? 

Functional boundary. Focus on identifying the current state, not action sequencing or error recovery. 

Skill-bank example. Title: Kettle State Observation 

Principle: Observe the state of the kettle and determine whether it is clean, dirty, or not visible in the current scene. 

When to apply: When determining the state of a kettle in a cleaning task, such as whether it needs cleaning or is already clean. 

Evidence: The agent failed to recognize that the kettle was not visible or not in the required state and therefore did not proceed with the cleaning task. 

Action-Planning Reflection View-specific instructions. 

Write one high-level planning skill that helps a future agent choose and order actions that advance a similar task. 

Think about: 

1. Which subgoal was active: search, open, take, clean, heat, cool, toggle, or place? 2. Which action advanced that subgoal given the known state and inventory? 3. What reusable ordering of subgoals follows from the comparison? 

Functional boundary. Focus on forward task execution, not state discovery or failure diagnosis. 

Skill-bank example. Title: Clean Kettle and Place in Stoveburner 

Principle: First, locate and examine the kettle to determine its state and location. Then, clean it using an appropriate method and place the cleaned kettle in the stoveburner. 

When to apply: When a task requires cleaning a kettle and placing it in a stoveburner, but its location or state has not yet been identified. 

Evidence: The agent repeatedly examined unrelated objects without locating the kettle and consequently failed to clean and place it in the stoveburner. 

Execution-Control Reflection View-specific instructions. 

Write one high-level control skill that helps a future agent detect, avoid, or repair execution errors. 

Think about: 

1. Which action precondition, task constraint, or completion condition was violated or overlooked? 2. Did the agent repeat an ineffective action, act on the wrong object, or advance before verifying the required state? 3. What should the agent verify, retry differently, or backtrack from? 

Functional boundary. Focus on verification and correction, not ordinary planning or initial state discovery. 

Skill-bank example. Title: Verify Preconditions Before Cleaning 

Principle: Verify that the object is in the correct location and that a cleaning facility, such as a sinkbasin, is available before performing the cleaning action. 

When to apply: When a cleaning action fails because the object location or required preconditions have not been confirmed. 

Evidence: The agent repeatedly examined incorrect objects and attempted cleaning without first verifying the kettle’s location or the availability of a valid cleaning facility.
