## 摘要
视频游戏为收集视觉-语言-动作（VLA）数据提供了实用场景，而在物理环境中采集此类数据成本高昂。然而，现有数据集仍受限于游戏覆盖范围有限、语言监督稀疏，或时间层级未必反映任务目标变化。我们提出 AceAction，一个涵盖多个3D游戏中人类游戏过程的数据集，用于学习技能组合与子目标转换。AceAction 围绕完整任务组织演示，将整体指令、有序子目标与局部技能指令关联到时间对齐的视觉观察和键鼠动作。为构建这些标注，我们开发了一个视觉-语言模型流水线，从目标或交互对象的变化中识别子目标，将导航目标锚定到视觉可识别的路点，并将相邻子目标组合为任务指令。所得演示涵盖导航、侦察、战斗、交互与恢复，并具有明确阶段边界，将任务进展与细粒度控制连接起来。我们通过基于模型的验证和人工检查评估标注质量。对500条轨迹的审核在独立评审者评估中达到95.8%的通过率。AceAction 为研究智能体如何在动态游戏环境中执行、组合和切换技能以遵循复杂指令提供了数据基础。

## Abstract
Video games provide a practical setting for collecting vision-language-action (VLA) data, whose acquisition in physical environments is costly. Existing datasets, however, remain limited by restricted game coverage, sparse language supervision, or temporal hierarchies that do not necessarily reflect changes in task objectives. We introduce AceAction, a dataset of human gameplay across multiple 3D games for learning skill composition and subgoal transitions. AceAction organizes demonstrations around complete tasks, linking overall instructions, ordered subgoals, and local skill instructions to temporally aligned visual observations and keyboard-and-mouse actions. To construct these annotations, we develop a vision-language model pipeline that identifies subgoals from changes in objectives or interaction targets, anchors navigation goals to visually recognizable waypoints, and composes adjacent subgoals into task instructions. The resulting demonstrations cover navigation, reconnaissance, combat, interaction, and recovery, with explicit stage boundaries that connect task progression to fine-grained control. We assess annotation quality through model-based verification and human inspection. An audit of 500 trajectories yields a 95.8% pass rate across independent reviewer assessments. AceAction provides a data foundation for studying how agents execute, combine, and switch skills to follow complex instructions in dynamic game environments.

## 1. 核心问题与研究动机

- **背景**：视觉-语言-动作（VLA）模型需要“语言目标—视觉观察—可执行动作”三元对齐的演示数据；在真实物理世界采集此类数据成本极高（需机器人硬件、人工监督、反复环境搭建）。
- **为何选游戏**：3D 电子游戏提供丰富虚拟环境，人类玩家可自然完成多样任务，键鼠输入与画面可同步录制，是低成本、大规模采集 VLA 数据的替代途径。
- **核心问题**：3D 游戏任务通常由多阶段技能组合构成（如接近建筑→侦察入口→交战→撤退恢复），智能体不仅要“会打”，还要理解每个技能服务于哪个子目标，并在阶段间正确切换。这要求数据同时具备：
  - **层级标注**：任务—子目标—技能级指令的显式连接，且带时间边界；
  - **大规模动作覆盖**：跨游戏、跨场景的细粒度键鼠轨迹。
- **现有数据集的三点不足**：
  - **EgoCS-400K**：仅限 Counter-Strike，以局部片段/动作链描述为主；
  - **Open-P2P**：游戏覆盖广，但指令稀疏、目标导向，缺乏细粒度技能与中间目标之间的监督；
  - **GameHorizon**：有多 horizon 指令，但层级按**预设时长区间**切分，可能切断持续子目标或合并多个短子目标，时间层级只是任务阶段结构的“不完美代理”。
- **论文定位**：提出 **AceAction-5M**，以“目标变化”而非“固定时长”作为阶段边界依据，统一多游戏任务、层级指令与时间对齐的键鼠轨迹。

## 2. 方法论

### 2.1 核心思想
围绕**完整任务**组织演示，构建 `整体指令 → 有序子目标（含起止时间边界）→ 局部技能/动作描述 → 帧级键鼠动作` 的四层对齐结构；用 VLM 流水线自动生成标注，并以“目标或交互对象变化”作为子目标切分准则。

### 2.2 数据来源与动作表示
- **自采数据**：内部全职、Gold 段位玩家（已获授权、匿名化转写），约 **1,891 小时**《Game for Peace》+ **261.17 小时**《Valorant》。
- **公开数据**：**2,103.05 小时** CS:GO/CS2 比赛录像、**811.50 小时** Open-P2P 已标注 3D 玩法、**113.25 小时** VPT Minecraft；合计约 **5,180 小时**。
- **动作空间**：键盘按键状态 + 鼠标按键（左/右/中/M4/M5/滚轮）+ 鼠标水平/垂直位移（yaw/pitch，DX/DY）。
- **采样率**：自采数据 16 Hz（每步 62.5 ms）；CS:GO/CS2 16 Hz；Open-P2P 与 VPT 保留原始 20 Hz。

### 2.3 标注流水线（三步）
1. **基于技能的子目标标注**
   - 每 **4 个连续动作**打包为一个标注单元，配一张对应视觉观察；
   - 轨迹按最多 **32 个单元**的滑动窗口顺序处理；
   - VLM 对每段联合预测：**技能类别、起止索引、子目标描述**；
   - 切分原则为“目的连续性”：只要服务于同一目标就保持一段，**主目标或交互对象改变**才开新段；
   - **跨窗口连续性**：后一窗口接收前一窗口末帧观察、技能类别与子目标描述，并预测 **continuation flag**；仅当 flag 为正、技能类别一致、序号相邻时才合并两段，使一个子目标可跨多个窗口；
   - 归一化类别/描述/边界，剔除残余的空中片段，用 source index 映射回原始图像—动作序列；
   - 共定义 **43 类技能**，覆盖导航、侦察、战斗、交互、恢复五类。
2. **基于路点的导航子目标标注**
   - 用最多 **8 帧**近期观察的滑窗（每步前进 1 帧）判断最新帧是否“抵达某具体地点”；
   - 输入含观察、动作、技能标注、已接受的路点名与最近路点；观察提供到达证据，动作与技能提供行为上下文；
   - 接受到达事件后，模型赋予**描述性路点名**并绑定源帧；同名地点复用旧名，已在同一地点内的持续活动不重复标注；
   - 以路点帧为终点采样不同长度片段，得到“同一目的地、不同起点与过程动作”的导航样本；模型据抽样关键帧（含首帧与到达帧）+ 完整动作序列 + 技能上下文 + 目标路点名，生成含路点名与路线描述的导航子目标（标注用关键帧，但输出保留完整图像—动作序列）。
3. **指令组合与校验**
   - 按执行顺序把同一轨迹的相邻子目标组合为**整体指令**，子目标保留为中间目标；可包含同技能连续段或跨技能转换（如导航后接交互）；
   - 保留整体指令、有序子目标描述、技能类别、段边界与对应图像—动作序列；
   - 导出前检查：描述非空、技能类别合法、边界有序且落在源序列内、图像—动作对应关系正确、每个导航片段确实终止于指定路点帧。

### 2.4 质量控制（两阶段）
- **模型验证**：Qwen3.8-27B 与 GLM-5.3-FLASH 双模型，自底向上三层核查（动作描述↔可见行为与记录控制；子目标↔观察与动作；整体指令↔子目标与完整轨迹），每层同时检查**视觉 grounding** 与**动作一致性**；任一模型在任一层拒绝即剔除。
- **人工检查**：8 名评审，**500 条轨迹**，每条至少 2 人独立评估；对照游戏片段与记录动作检查三层标注；独立评审记录通过率 **95.8%**。

## 6. 主要结论与发现

- 提出并开源/构建 AceAction-5M：跨多款 3D 游戏、约 5,180 小时、5.48M 任务指令实例、115.93M 键鼠动作的层级化 VLA 数据集。
- 以“目标/交互对象变化”定义阶段边界，比按时长切分更贴近真实任务结构，可把“何时切换子目标”从数据隐含属性变成**显式可学习信号**。
- 路点锚定能把自由文本导航目标落到视觉可识别地点，并生成“同终点、不同起点”的多样化导航样本。
- 双 VLM 逐层验证 + 人工抽检的两阶段质控可达到 **95.8%** 的独立评审通过率，说明自动标注流水线在实践中可用。
- 数据覆盖导航、侦察、战斗、交互、恢复五类行为，为研究任务分解、技能组合与子目标切换提供结构化监督基础。

## 7. 优点（亮点）

- **标注范式有针对性**：直击 GameHorizon 等“按时长切分”导致层级失真的痛点，用语义目标变化定义边界，并引入 continuation flag 解决跨窗口子目标断裂。
- **三层对齐完整**：整体指令 / 子目标 / 动作描述三层同时绑定时间边界与帧级键鼠动作，兼顾“做什么”和“怎么做”。
- **路点机制巧妙**：把导航目标锚定到可复用的命名地点，既提高标注可验证性，又天然生成多起点—同终点的对照样本，利于学习路线泛化。
- **质控流程较严谨**：双模型 + 三层 + 双维度（视觉 grounding / 动作一致性）的“全层通过才保留”策略，再加人工抽检，比单一模型过滤更稳健。
- **数据规模与多样性**：多游戏、多技能类别（43 类）、自采与公开数据互补，动作表示统一（键鼠 + 鼠标位移），便于跨游戏混合训练。
- **工程细节完备**：source index 回溯、边界合法性检查、导航片段终点校验等，保证语义标注与原始序列严格对应。
