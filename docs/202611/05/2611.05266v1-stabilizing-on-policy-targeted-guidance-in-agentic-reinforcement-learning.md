## 摘要
朴素同策略强化学习常受基座模型能力的瓶颈限制——覆盖不足会导致无法从某些奖励中学习。同时，现代后训练系统中的奖励往往来自丰富的文本来源，例如带有评分标准细则的评判模型。我们能否利用这类结构提供丰富的方向性信号，从而改进原本难以优化的奖励？本文研究一个我们称为定向引导的框架，它通过同策略自蒸馏目标从逐轮文本反馈中学习。我们不仅关注直接改进难以优化的行为，也关注如何在训练全过程中实现这一点而不降低基线强化学习性能。在智能体多轮软件工程环境中的一系列设置下，我们发现，将定向自蒸馏与按标准逐项计算的强化学习奖励相结合，并将反馈限制在策略具体失败的轮次，能够取得成功。我们进一步考察了有助于在训练过程中保持熵稳定并减少振荡行为的设计选择。

## Abstract
Naive on-policy RL is often bottlenecked by the capabilities of the base model --- insufficient coverage can result in an inability to learn from certain rewards. At the same time, rewards in modern post-training systems often come from rich textual sources, e.g. judge models with a rubric of criteria. Can we utilize such structures to provide a rich directional signal that enables improving on otherwise difficult to optimize rewards? In this work, we examine a framework we refer to as targeted guidance that learns from per-turn textual feedback via an on-policy self-distillation objective. Our focus is not only on directly improving hard-to-optimize behaviors, but on how to do so throughout the training process without degrading baseline RL performance. Over a range of settings across an agentic multi-turn software engineering environment, we find success by combining targeted self-distillation with a per-criteria RL reward, and by limiting feedback to turns where the policy specifically fails. We further examine the design choices that lead to stable entropy and reduce oscillatory behavior throughout training.

## 一、核心问题与研究动机

- **背景瓶颈**：朴素同策略（on-policy）强化学习（RL）常受限于基座模型自身的能力与覆盖范围。若目标行为落在基座策略的支持集之外，即使奖励函数设计得当，策略也难以通过采样“碰巧”做出该行为，从而无法学习——在多轮工具调用、需要串联复杂动作的智能体场景中尤为突出。
- **信息浪费**：现代后训练系统的奖励往往来自丰富的文本源（如带评分细则的评判模型 judge），但朴素 RL 把这些信号压缩成单一标量，损失了大量方向性信息。
- **核心追问**：RL 只能“激励已有好行为”，却不能“告诉模型如何做出新行为”。论文希望利用已有的逐条文本反馈，提供**丰富的方向性改进信号**，以优化原本难以优化的奖励标准。
- **研究定位**：目标不仅是直接改善难优化行为，更关键的是**在训练全过程中引入该信号而不损害基线 RL 性能**（最小化 regret），并解决同策略自蒸馏常见的推理缩短、多样性崩塌、熵不稳定等问题。

## 二、方法论

### 核心思想
- 提出 **Targeted Guidance（定向引导）** 框架：把每条二元奖励准则对应的**文本反馈字符串** f 插入到出问题的智能体轮次之前，构造一个“专家”策略 μ——它与当前策略**共享同一套权重**，只是上下文中多了反馈 f。
- 通过**逐 token 的 KL 蒸馏**把专家行为内化到当前策略中，作为标准策略梯度之外的方向性信号。
- 理论启发：基于经典策略改进论证，希望专家满足两个启发式条件——(1) 在当前策略状态分布下期望优势为正（Eq.1）；(2) 专家与当前策略的 KL 差异尽量小（Eq.2），即“只改该改的地方”。

### 关键技术细节
- **反馈定位与掩码**：反馈字符串只插在受影响的那一轮之前，KL 损失只在**含失败准则的智能体轮次**上计算，其余轮次全部 mask，以最小化不必要的蒸馏压力。
- **与 RL 奖励结合**：蒸馏负责“教会”新行为，逐准则的标准 RL 奖励负责“保留并精炼”该行为，二者互补。
- **完整目标函数**（Eq.3）：
  \[
  L(\theta)=L_{\text{GRPO}}(\theta)+\lambda\sum_{t\in F}\mathrm{KL}\big(\pi_\theta(\cdot|s_t)\,\|\,\mathrm{sg}(\pi_\theta(\cdot|s_t,f_t))\big)
  \]
  其中 F 为失败轮次集合，f_t 为该轮反馈，λ 为蒸馏权重，sg 表示停止梯度。
- **KL 实现**：采用全词表 KL（trainer 侧计算，非采样估计），以缓解推理-训练不匹配；默认用反向 KL（forward-KL、JS、Rao-Blackwellized KL 实验表现相近）。
- **归一化**：KL 项在整条 rollout 的所有 token 上归一化，降低长 rollout（如循环推理）的影响。
- **反馈设计流程**：用候选反馈字符串查询基座模型，测量其相对无上下文模型的平均表现，**只保留能带来平均提升的反馈提示**。
- **渐近无偏性论证**：由于蒸馏仅作用于失败轮次，当所有准则持续满足时，损失退化为标准策略梯度，因此（在最优策略存在时）可收敛到最优策略。
- **计算成本**：教师仅用于 logit 级引导，无需自回归生成；额外开销约为**一次前向传播**获取专家 logit，显存可通过只物化最后一层隐表示的 kernel 缓解。

## 六、主要结论与发现

- **定向引导可教会“支持集之外”的行为**：新工具格式在朴素 RL 完全学不会的情况下被成功掌握，且编码通过率无回退；信号随行为被修复而自动衰减至近零。
- **多准则场景显著优于基线**：TG 在 7 条风格准则上大幅领先（如 Markdown 0.85 vs GRPO 0.00，审批 0.55 vs 0.00），同时通过率保持 0.33，与 GRPO 持平；OPSD 风格提升不稳定且通过率略降（0.30）；Online SFT / LaTRO / Verifree 出现明显通过率退化（0.26 / 0.14 / 0.20）。
- **每轮交错反馈同样有效**：俳句式状态汇报这一强分布外行为可被学会，GRPO 完全失败；朴素 OPSD 能学到但不稳定且通过率回退；“始终提供反馈”变体也导致通过率回退——**失败门控是必要的**。
- **稳定性机制**：
  - 蒸馏权重过高 → 熵尖峰 → 输出长度上升 → 通过率崩塌；较低静态权重即可停留在稳定区间。
  - **将蒸馏施加到 thinking token 至关重要**：否则风格准则剧烈振荡；加入后曲线单调稳定，thinking trace 中出现对多条准则的自我提醒，实现组合式遵循。
- **理论性质**：由于失败门控，全准则满足时损失退化为标准策略梯度，方法渐近无偏。

## 七、优点

- **信号利用巧妙**：把 judge 的文本反馈转化为逐 token 的方向性蒸馏信号，避免了标量化奖励的信息损失。
- **“最小干预”设计**：反馈只插在出错轮次前、损失只 mask 到失败轮次，天然贴合 Eq.2 的“专家尽量接近原策略”启发式，降低对基线任务的干扰。
- **蒸馏 + RL 的协同**：用蒸馏解决探索/覆盖，用无偏 RL 保证收敛与精炼，二者分工清晰。
- **稳定性洞察有实践价值**：熵尖峰作为崩溃早期预警

- **稳定性洞察有实践价值**：熵尖峰可作为崩溃早期预警，用于调节蒸馏权重或提前止损；失败门控与 thinking token 覆盖分别回答了“何时蒸馏”和“蒸馏什么”，比单纯调参更具机制解释性。
- **反馈筛选降低噪声**：先验证候选反馈字符串是否相对无上下文模型带来平均提升，再将其作为教师信号，避免把无效甚至有害的文本反馈直接注入训练。
- **渐近无偏与低生成成本兼顾**：失败门控使全准则满足时损失退化为标准策略梯度；教师仅用于 logit 级引导，无需自回归生成，额外成本主要是一次前向传播，工程上较易接受。
- **实验对比较规范**：蒸馏类方法尽量共享同一蒸馏算子、token 覆盖范围和超参扫描流程，并对异步 RL 下部分基线的天然劣势作出说明，结论解释相对克制。

## 八、局限与可改进之处

- **外部效度有限**：实验集中在单一软件工程智能体环境与单一基座模型（Qwen3-Coder-30B），尚不能证明方法可泛化到其他工具集、其他模型规模或开放式对话/多模态智能体。
- **引导目标偏风格与格式**：主要验证的是工具参数格式、7 条风格准则和每轮俳句汇报，虽包含多轮交错行为，但对核心推理能力、长程规划或复杂工具组合能力的提升证据不足。
- **反馈质量依赖外部 judge**：方法把文本反馈当作专家上下文，若 judge 反馈本身错误、模糊或与任务目标冲突，蒸馏可能放大错误方向；论文虽做了反馈筛选，但未系统评估反馈噪声鲁棒性。
- **理论保证条件较强**：渐近无偏性依赖“最优策略存在”以及失败门控最终退化为标准策略梯度的理想条件；在异步训练、策略滞后和有限采样下，实际收敛行为仍需更细的理论刻画。
- **超参与显存开销仍敏感**：蒸馏权重过高会导致熵尖峰和通过率崩塌；全词表 KL 虽比采样估计更稳，但大词表下的 logit 物化仍带来显存压力，论文未给出实测吞吐与硬件数据。
- **基线覆盖不完整**：作者自承未能将大量 OPSD 变体移植到本设定下做头对头比较；Online SFT、LaTRO、Verifree 在异步设定下可能天然吃亏，公平性解释虽合理但仍影响结论强度。
- **缺少系统性消融拆解**：对“反馈插入位置”“KL 方向”“归一化方式”“教师停止梯度”等原子设计选择缺乏类似“what matters”式的系统实验，难以判断各组件贡献的相对大小。
- **潜在风格过拟合与奖励黑客风险**：逐准则奖励与蒸馏共同作用时，模型可能学会机械满足表面格式而偏离真实任务质量；当前通过率持平只能部分缓解这一担忧。

## 九、启发与展望

- **把文本反馈转化为 token 级方向信号**是本文最具迁移价值的思路：在奖励可验证但难优化的场景中，可用 judge 反馈构造“同权重专家”，以最小干预方式补足探索。
- **失败门控是一种通用的稳定化范式**：只在出错轮次施加蒸馏，既降低对已掌握行为的干扰，也使引导信号随能力修复自然衰减，可推广到多轮对话、代码修复和工具调用纠错。
- **蒸馏与 RL 的分工值得继续研究**：蒸馏负责“教会新行为”，RL 负责“保留并精炼”，未来可探索自适应权重、按准则难度调度蒸馏强度，以及将反馈粒度从轮次级细化到步骤级。
- **诊断指标应纳入训练监控**：熵、输出长度、thinking trace 内容和逐准则满足率可作为早期预警，帮助区分“探索不足”与“蒸馏过强”两类失败模式。
- **后续工作可扩展方向**：跨模型/跨环境复现、引入反馈噪声与对抗 judge 测试、与更多 OPSD/在线蒸馏变体公平比较、报告完整算力与吞吐，并在核心推理任务上验证是否不仅改善风格而是提升真实能力。

## 十、总体评价

本文针对同策略智能体 RL 中“奖励可定义但行为难采样”的瓶颈，提出了一个结构清晰、干预克制且工程可行的定向引导框架。其核心贡献不在于提出全新的 RL 目标，而在于把丰富的文本反馈转化为逐 token 的专家蒸馏信号，并通过失败门控、thinking token 覆盖和与标准策略梯度的结合，缓解了同策略自蒸馏常见的熵不稳定、推理缩短和多样性崩塌问题。实验在工具格式纠正、多准则风格遵循和多轮交错行为三类递增难度场景中展示了较强说服力，尤其揭示了“失败门控必要”和“thinking token 必须参与蒸馏”两个有实践价值的稳定化条件。与此同时，论文的外部效度、反馈噪声鲁棒性、算力报告和基线覆盖仍有提升空间，引导目标也更多集中在风格/格式而非核心智能。总体而言，这是一篇问题意识明确、方法设计精巧、实验诊断较扎实的工作，适合作为“利用文本反馈稳定化同策略定向引导”的框架性起点，但其结论宜在更广泛环境和任务上进一步验证。
