# ABSTRACT 

Offline multi-task reinforcement learning (MTRL) aims to learn a unified policy from heterogeneous offline datasets that generalizes across tasks. However, ex-isting offline MTRL methods often struggle with two fundamental issues: severe per-task data scarcity and limited cross-task generalization. In this paper, we pro-pose Language-Model Augmented Decision Transformer (LaMA-DT), a unified sequence-modeling framework that leverages a single large language model (LLM) for both trajectory augmentation and multi-task policy learning. LaMA-DT uses natural-language task descriptions to guide task-aligned trajectory augmentation through a set of supervised generation and alignment objectives, and incorporates a scoring-and-filtering mechanism to retain high-quality augmented trajectories. The same LLM is then repurposed as a language-conditioned Decision Trans-former and fine-tuned on a mixture of real and augmented data. Experiments on Meta-World and MuJoCo multi-task benchmarks demonstrate that LaMA-DT consistently outperforms competitive baselines, particularly in low-data regimes, showing that language-guided data augmentation substantially improves cross-task generalization. 

# 1 INTRODUCTION 

Offline reinforcement learning (RL) (Levine et al., 2020) enables agents to learn high-quality decision policies directly from static datasets. To extend offline RL to more realistic applications, it is important to handle multi-task settings, where an agent must solve multiple related tasks that share state and action spaces but differ in goals, rewards, or context. This motivates offline multi-task RL (MTRL) (Yu et al., 2020b), which learns from heterogeneous offline datasets and aims to produce a single policy that can perform well across tasks. In practice, offline MTRL is limited by two tightly coupled challenges. First, per-task data is often scarce: each task may have only a small and fragmented dataset, since collecting trajectories for many tasks is expensive and often infeasible. Second, cross-task generalization is difficult: tasks vary in objectives, dynamics, and observation distributions, leading to substantial distribution shifts that hinder learning a single policy across tasks, especially when limited state–action coverage further amplifies these shifts. Existing offline MTRL methods offer partial solutions, but typically target only one challenge or rely on strong data assumptions. For improving data use across tasks, CDS (Yu et al., 2021) transfers transitions from auxiliary tasks to a target task based on estimated usefulness. While effective when abundant and closely related auxiliary data are available, CDS struggles with cross-task generalization, as it requires training a separate model for each target task and degrades when auxiliary data are scarce or poorly matched. SRTD (Yoo et al., 2022) learns a shared latent skill space and performs data augmentation via imagined rollouts; however, learning a stable and transferable latent representation generally requires sufficient task-specific data. When per-task datasets are limited, the learned latent space becomes unreliable, reducing the effectiveness of the generated rollouts. A separate line of work builds on Decision Transformers (DTs) (Chen et al., 2021) and adapts them to multi-task learning to 1arXiv:2611.04031v1 [cs.CL] 2 Nov 2026 Preprint improve generalization through shared sequence modeling. For example, HarmoDT (Hu et al., 2024) improves parameter sharing by reducing gradient conflicts across tasks, and SoCo-DT (Wang et al., 2025) refines sharing via Fisher-information–guided soft masks. However, these DT-based MTRL methods still typically rely on having enough trajectories per task to learn transferable sequence representations; when each task has limited data, performance can drop sharply due to insufficient coverage and overfitting to narrow task-specific patterns. These gaps naturally raise a question: 

In offline MTRL under low-data regimes (i.e., with scarce task-specific data), how can we expand effective data coverage while achieving robust cross-task generalization? 

A key observation is that, although per-task trajectories are limited, high-level task descriptions are almost always available. Such descriptions convey information such as the task name, goal, object identity, or expertise level, which can be succinctly expressed in natural language. This motivates our approach: use natural language as a task-specification medium to guide trajectory augmentation via large language models (LLMs), thereby improving multi-task policy learning in data-scarce scenarios. However, since LLMs are not pretrained on trajectory data, realizing this idea requires ensuring that augmented trajectories both remain faithful to limited real data while expanding state–action coverage, and stay aligned with task descriptions to prevent cross-task drift. In this paper, we propose Language-Model Augmented Decision Transformer (LaMA-DT) for offline MTRL, which employs a single LLM for both trajectory augmentation and multi-task policy learning. To enable high-quality, task-aligned trajectory generation, the LLM is first fine-tuned across tasks using four carefully designed supervised objectives that jointly capture environmental dynamics and temporal dependencies in sequential decision-making. To further ensure semantic alignment between natural-language task descriptions and generated trajectories, LaMA-DT incorporates two additional task–trajectory alignment objectives. All six objectives are jointly optimized under a dedicated multi-objective fine-tuning strategy tailored for LLM-based trajectory learning. To ensure that only high-quality augmented trajectories are used for policy learning, we introduce a likelihood-based scoring-and-filtering mechanism that evaluates generated trajectories across all objectives and discards low-quality or task-misaligned samples. Finally, the same LLM is repurposed as a DT—a natural choice for sequence modeling—conditioned on natural-language task descriptions and fine-tuned on a mixture of real and high-quality augmented trajectories, resulting in robust cross-task generalization. Key contributions are summarized as follows: • We propose LaMA-DT, an LLM-based offline MTRL framework that unifies trajectory augmen-tation and multi-task policy learning. It addresses data scarcity by leveraging natural-language task descriptions to guide task-aligned trajectory augmentation via a set of objectives that capture task-specific data distributions and enforce semantic alignment. • To enable cross-task generalization in offline MTRL, LaMA-DT introduces an LLM-based policy learning mechanism that combines scored and filtered high-quality augmented trajectories with original data, conditioned on task descriptions, to fine-tune a DT initialized from the same LLM, yielding improved cross-task generalization. • LaMA-DT demonstrates consistent improvements over competitive baselines on Meta-World and MuJoCo multi-task benchmarks, with particularly strong gains in low-data regimes , highlighting that effective data augmentation substantially enhances multi-task learning performance 1.

# 3 METHODOLOGY 

In this section, we present Language-Model Augmented Decision Transformer (LaMA-DT) for offline MTRL, which employs a single LLM for both trajectory augmentation and multi-task policy learning. Fig. 1 illustrates the framework overview. 3.1 TASK DESCRIPTIONS IN OFFLINE MTRL A central difficulty in offline MTRL is data scarcity: per-task datasets are often small, making it difficult to learn reliable policies that generalize across tasks. Although trajectory data are scarce, rich task-level metadata are almost always available. Such metadata—including task names, goals, relevant objects, environmental conditions, and typical performance—can be naturally expressed in natural language. This observation motivates the use of natural-language task descriptions to guide an LLM in generating additional, task-aligned trajectories, leveraging its strong sequence-modeling and reasoning capabilities to expand effective data coverage and thus mitigate data scarcity. To operationalize this idea, we construct a standardized natural-language description for each task 3Preprint 

Ti ∈ T using a simple template: “This is the [task_name], and its goal is to [task_goal]. The environment is [environment_description]. and episodes run up to [max_episode_length] steps. The trajectories show [expertise_level] performance.”

3.2.1 TASK -S PECIFIC TRAJECTORY GENERATION 

We design four trajectory-generation objectives (O 1–O 4) to fine-tune the LLM, enabling it to capture environmental dynamics, temporal dependencies in sequential decision-making, and task-specific data distributions, thereby generating plausible trajectories that resemble the available data while effectively expanding state–action coverage. 

Dynamics Learning Objective. We first equip the LLM with an explicit understanding of environ-ment dynamics to ensure physically grounded trajectory generation via O 1:

Objective 1: Dynamics Prediction (O 1). Accurate modeling of dynamics is essential to prevent physically implausible trajectories ( e.g. , a robot arm violating joint limits or a locomotion agent defying gravity). O 1 fine-tunes the LLM to predict the next state s′ given the current state s and action a in a supervised manner, enabling it to capture the transition dynamics. For each task Ti,the LLM receives its task description pi along with the prompt: “Predict the next state given the current state and action (s, a ).” 

Sequential Decision Learning Objectives. Beyond modeling environmental dynamics, we design O2–O 4 to capture temporal dependencies in sequential decision-making across different tasks from complementary perspectives, while also reinforcing the dynamics learned in O 1:

Objective 2: Trajectory Interpolation (O 2). O2 is designed to generate plausible intermedi-ate states, actions, and rewards between two observed points along a trajectory. This objec-tive encourages the LLM to preserve local temporal consistency, ensuring that short-horizon transitions remain coherent within the overall trajectory and thereby reducing error accumu-lation in long-horizon rollouts. In practice, we randomly select two states from a real tra-jectory as the start and end states, and use the ground-truth subtrajectory between them as supervision. For O 2, the LLM is provided with the task description pi for task Ti along with the prompt: “Fill in the missing part of the trajectory given the start state and action (s0, a 0) and the final state sT .” 

Objective 3: Trajectory Forward Generation (O 3). Forward generation is a core capability for trajectory modeling: given an initial state–action pair, the model should be able to generate a plausible rollout over time. O3 aims to capture long-horizon temporal dependencies by encouraging the LLM to maintain consistency throughout the trajectory in the forward direction. Specifically, O 3

fine-tunes the LLM in a supervised manner to generate complete trajectories starting from (s0, a 0),using trajectories from Di as ground-truth supervision. For O 3, the LLM is provided with the task description pi for task Ti along with the prompt: “Generate the whole trajectory until termination given the start state and action (s0, a 0).” 

Objective 4: Trajectory Backward Generation (O 4). Human learning often relies on bidirectional reasoning: we not only predict future consequences from a current state but also reason backward from a desired outcome. A similar capability is valuable for trajectory generation. Relying solely on forward prediction may lead to error accumulation or trajectories that diverge from the intended task goal—especially in multi-task settings where tasks may share similar local dynamics but differ substantially in their global objectives. O 4 is designed to address this issue by fine-tuning the LLM to reconstruct trajectories backward from a given final state with supervision. For O 4, the LLM is provided with the task description pi for task Ti along with the prompt: “Reconstruct the trajectory backwards from the final state sT .” 

4Preprint 3.2.2 TASK –T RAJECTORY ALIGNMENT 

However, O 1–O 4 rely primarily on limited task-specific trajectories as supervision and do not explicitly enforce alignment between generated trajectories and the intended task description pi. As a result, the LLM may learn to generate coherent and physically plausible trajectories driven mainly by data supervision, while failing to respect the specified task descriptions. Such task–trajectory drift is particularly problematic in multi-task settings, where different tasks often share similar state–action distributions yet differ fundamentally in their goals. To address this gap, we introduce two task–trajectory alignment objectives (O 5–O 6) that explicitly couple generated trajectories with their natural-language task descriptions: 

Objective 5: Trajectory Explanation (O 5). O5 trains the LLM to map trajectories to natural-language explanations in a supervised manner, requiring it to interpret behavioral patterns and infer the underlying task intent. By learning to articulate what a trajectory accomplishes, the LLM develops a semantic understanding of task goals, allowing it to distinguish trajectories based on purpose rather than merely imitating plausible motion patterns. Given a specific trajectory τ and an explanatory prompt ( i.e. , “ Explain the following trajectory in natural language. ”), the model is trained to produce a description summarizing the task goal and the executed behavior. 

Objective 6: Description-Based Rollout (O 6). O6 trains the LLM to generate trajectories directly from natural-language task descriptions, enabling conditional planning across diverse tasks based on semantic understanding. Given a task description pi, an initial state s0, and an expected return 

r, the model is trained to produce a trajectory ˜τ that fulfills pi. By explicitly grounding trajectory generation in the semantics of pi, O 6 ensures that the LLM produces task-aligned behaviors—an ability that is critical in multi-task settings where different tasks may share similar initial states or final rewards yet require fundamentally different goals and behaviors. O5 and O 6 form a bidirectional pair that establishes a semantic feedback loop: O 5 maps trajectories to task descriptions ( τ → pi), while O 6 performs the inverse mapping from task descriptions to trajectories ( pi → τ ). When interleaved with O 1–O 4, these alignment objectives prevent the model from drifting toward goal-agnostic generation and ensure that augmented trajectories are not only physically plausible but also semantically consistent with their intended task descriptions. 3.2.3 MULTI -O BJECTIVE LLM F INE -T UNING .To mitigate gradient interference among the heterogeneous supervision objectives O 1–O 6, we in-troduce an objective-aware fine-tuning strategy utilizing LoRA (Hu et al., 2022). # 4 EXPERIMENTS 

Our experiments are designed to answer the questions: (Q1) How does LaMA-DT compare with strong offline MTRL baselines on benchmarks? (Q2) In low-data regimes, does LaMA-DT retain advantages over data-hungry multi-task DT variants? (Q3) Does LaMA-DT exhibit consistent perfor-mance gains across offline datasets of varying quality? (Q4) How does the amount of augmented data influence performance in both standard- and low-data regimes? (Q5) Are the individual components of LaMA-DT critical? (Q6) Are the augmented data in LaMA-DT high-quality? 

Experimental Setup. We evaluate LaMA-DT on two widely used offline MTRL benchmarks: MuJoCo (Todorov et al., 2012) and Meta-World (Yu et al., 2020b). For MuJoCo locomotion, we follow prior prompt-based Decision Transformer protocols (Xu et al., 2022) and report results on Cheetah-dir, Cheetah-vel, and Ant-dir. For Meta-World, we use the ML5 and ML30 task suites with shared Sawyer robot dynamics, and evaluate performance using the average success rate across tasks. Offline datasets are collected using SAC (Haarnoja et al., 2018). We consider two dataset settings: (i) a near-optimal setting consisting primarily of expert trajectories, and (ii) a sub-optimal 

setting comprising 50% expert and 50% non-expert trajectories. For low data regimes, we uniformly subsample the per-task training data to {1%, 5%, 10%} of the full dataset. All results are averaged over 3 seeds, and each task is evaluated for 50 episodes. 

Baselines. We compare LaMA-DT against representative offline MTRL baselines: (i) CDS (Yu et al., 2021), which applies a conservative transition-sharing strategy across tasks; (ii) MTBC (Hu et al., 2024), a multi-task behavior cloning approach using network scaling and task-ID–conditioned actors; (iii) MTIQL (Kostrikov et al., 2021a), which extends IQL to the multi-task setting with task-conditioned actors and critics; (iv) MTDIFF (He et al., 2023), a diffusion-based generative planner for multi-task RL; (v) MTDT (Chen et al., 2021), a multi-task DT conditioned on task IDs; (vi) Prompt-DT (Xu et al., 2022), which leverages trajectory prompts and return-to-go conditioning on DT; and (vii) HarmoDT (Hu et al., 2024), a prompt-based DT with task-specific masking.

Performance in Low-Data Regimes (Q2). In Table 2, across all benchmarks and data fractions, LaMA-DT consistently outperforms DT-based baselines, demonstrating substantial advantages in low-data regimes. It achieves consistent gains on both ML30 and Cheetah-dir across all data levels (1%, 5%, and 10%), with performance improving steadily as more data become available. For example, on ML30 with suboptimal offline data, LaMA-DT improves from 15.7 at 1% data to 51.8 at 10%, significantly outperforming Prompt-DT (by 22.7% at 1% and 40.8% at 10%) and HarmoDT (by 29.8% at 1% and 21.6% at 10%), indicating superior data efficiency. A similar trend is observed on Cheetah-dir: under near-optimal data, it outperforms HarmoDT by 47.3% and Prompt-DT by 58.5% on average across the three data fractions. Notably, even in the extreme 1% regime, LaMA-DT maintains a clear margin over all baselines, highlighting its robustness under severe data scarcity. 

Robustness to Data Quality (Q3). Table 2 shows that LaMA-DT consistently maintains a clear performance advantage over competing methods under both sub-optimal and near-optimal datasets. Notably, LaMA-DT substantially outperforms DT-based baselines in the sub-optimal setting, demon-strating strong robustness to imperfect offline data. As data quality improves, LaMA-DT exhibits larger absolute performance gains than competing approaches: on Meta-World ML30 at the 5% data level, performance increases from 39.1 (sub-optimal) to 52.6 (near-optimal), a gain that is significantly larger than those achieved by Prompt-DT or HarmoDT. # 5 CONCLUSION 

We presented LaMA-DT, an LLM-based offline MTRL framework designed to address data scarcity and cross-task generalization. LaMA-DT leverages specialized fine-tuning objectives to enable a sin-gle LLM to generate high-fidelity, task-aligned trajectories for augmentation. The same LLM is then repurposed as a DT and fine-tuned on both augmented and real trajectories. Experiments demonstrate that LaMA-DT consistently outperforms state-of-the-art offline MTRL baselines, highlighting the effectiveness of LLM-driven trajectory augmentation and policy learning. # A RELATED WORK 

Offline RL. Offline reinforcement learning learns policies from fixed datasets without additional environment interaction (Levine et al., 2020; Ernst et al., 2005; Lange et al., 2012), and has shown promise in robotics (Kalashnikov et al., 2018; Rafailov et al., 2020), NLP (Jaques et al., 2019), and healthcare (Wang et al., 2018). A central challenge is distribution shift between the learned policy and the behavior policy, which can lead to erroneous value backups and unstable learning (Fujimoto et al., 2018; Levine et al., 2020). To address this, prior work constrains the policy to stay close to the behavior distribution (Kumar et al., 2019; Fujimoto et al., 2018; Wu et al., 2019; Jaques et al., 2019; Peng et al., 2019; Siegel et al., 2020) or regularizes the learned value/Q functions (Kumar et al., 2020; Kostrikov et al., 2021b), while model-based approaches build conservative dynamics/reward models to reduce out-of-distribution errors (Kidambi et al., 2020; Yu et al., 2020c). In addition, Decision Transformer (Chen et al., 2021) casts offline RL as conditional sequence modeling. 

Multi-task RL and offline MTRL. Multi-task RL studies learning a shared policy across tasks in RL settings. A key obstacle is negative transfer caused by conflicting gradients across tasks, motivating gradient-surgery or conflict-aware optimization methods (Yu et al., 2020a; Chen et al., 2020; Liu et al., 2021). Multi-task offline RL aims to learn a shared policy from offline datasets collected from a set of tasks. A common formulation is to train a task-conditioned policy under a unified objective, but such shared training often suffers from negative transfer caused by conflicting gradients across tasks and heterogeneous data sources. To mitigate this issue, prior work has explored selective sharing and conflict-aware optimization mechanisms. HarmoDT (Hu et al., 2024) addresses this challenge from a parameter-selection perspective by learning task-specific binary masks over shared parameters, enabling conflict-aware parameter sharing in multi-task offline Decision Transformer training. Complementary to gradient conflict handling, data sharing methods selectively reuse transitions across tasks while remaining conservative under distribution shift, such as CDS (Yu et al., 2021) and related value-based sharing approaches (Eysenbach et al., 2020; Kalashnikov et al., 2021; Yu et al., 2022). More recently, M3DT (Kong et al., 2025) introduces a Mixture-of-Experts Decision Transformer to scale offline MTRL to massive task suites by decoupling task load across expert subsets. However, M3DT targets task scalability under full per-task datasets , an axis orthogonal to our focus on per-task data scarcity : LaMA-DT addresses scarcity through language-guided trajectory augmentation rather than through architectural expansion. In contrast to these baselines, LaMA-DT aligns text and behavior, and then uses the resulting objectives to score and filter generated trajectories before decision-transformer policy learning, leading to more robust multi-task offline RL. 

Offline Meta-RL. Offline meta-RL aims to learn policies that generalize to unseen tasks from fixed offline datasets, without any online interaction. A large body of prior work follows the temporal-difference (TD) paradigm, using either optimization-based meta-learning to find fast-adaptable initializations (Finn et al., 2017; Mitchell et al., 2021; Xu et al., 2018). However, TD-based offline meta-RL can be prone to instability under off-policy bootstrapping (Levine et al., 2020), motivating alternative approaches that avoid value backups. Along this line, decision-transformer-style methods treat offline meta-RL as conditional sequence modeling over trajectories (Chen et al., 2021). Prompt-based approaches such as Prompt-DT (Xu et al., 2022) and DPDT (Zheng et al., 2024) adapt to new tasks using soft or hand-crafted prompts, while GDT (Furuta et al., 2021) leverages hindsight rewards as an adaptation signal. Meta-DT (Wang et al., 2024) further introduces a meta-policy to select infor-mative trajectories for adaptation. Two contemporaneous approaches further inject language signals into this paradigm: LPDT (Yang & Xu, 2025) initializes Prompt-DT with a pre-trained language model and adds prompt regularization to improve few-shot adaptation, while T2DA (Zhang et al., 2025) learns CLIP-style contrastive alignment between task descriptions and trajectory embeddings to enable zero-shot transfer. Both methods leverage language to ground task semantics, but they differ from LaMA-DT in two important ways: (i) neither performs trajectory-level data augmentation —LPDT relies on LM initialization while T2DA relies on contrastive alignment—and (ii) both are evaluated primarily under the meta-RL zero/few-shot transfer protocol, whereas LaMA-DT addresses the multi-task offline setting under varying per-task data fractions. We accordingly compare against multi-task offline RL baselines that share our evaluation protocol, and view direct comparison with LPDT and T2DA on their meta-RL setups as a complementary direction. Our work builds on the sequence-modeling perspective, but explicitly leverages natural language task descriptions to ground task semantics in behavioral data, also enabling generalization ability in offline meta-RL settings. 14 Preprint 

LLM-based offline RL. A complementary line of work directly leverages pre-trained language models for offline RL. LaMo (Shi et al., 2024) initializes the DT backbone with a frozen pre-trained language model and fine-tunes via LoRA on a small fraction of parameters, demonstrating substantial gains in single-task offline RL—especially under sparse rewards and limited data. LaMA-DT extends this direction along two axes: (i) we operate in the multi-task offline setting rather than per-task training, requiring explicit mechanisms to disambiguate similar state-action distributions across tasks; and (ii) we reuse the same LM not only as the policy backbone but also as a trajectory generator 

that produces task-aligned augmented data via six supervised objectives, addressing the data scarcity bottleneck that initialization alone cannot resolve.

# C ENVIRONMENT DETAILS 

C.1 META -W ORLD 

The Meta-World benchmark (Yu et al., 2020b) is a comprehensive suite of robotic manipulation tasks designed to evaluate generalization and multi-task learning in continuous control. It involves a Sawyer robotic arm performing 50 distinct manipulation tasks (MT50), each characterized by unique object geometries, joint configurations, and goal dynamics. The robot operates in a 4-dimensional fine-grained continuous action space, controlling the 3D end-effector position and gripper openness. Following recent advances in multi-task RL (Yang et al., 2020; Hu et al., 2024), we employ the random-goal variant (MT50-rand), where goal positions are randomized per episode to promote adaptability and discourage overfitting to fixed targets. In our experiments, we focus on a subset of 30 tasks (ML30) to balance computational efficiency with comprehensive evaluation across diverse manipulation skills. The primary evaluation metric is the average success rate across tasks, reflecting the robot’s capacity to generalize under varied and unseen goal configurations. For offline data collection, we adopt the Soft Actor-Critic (SAC) algorithm (Haarnoja et al., 2018) to train individual policies for each task until convergence. For every task, we record 1M transitions during training, resulting in a comprehensive offline dataset composed of both successful and failed attempts. Based on the convergence stage, we curate two datasets matching the main-text definitions: • Near-Optimal (NO): the complete 1M transitions per task collected from the converged SAC policy, dominated by expert behavior. • Sub-Optimal (SO): a 1M-transition mixture of (i) 0.5M expert transitions sampled from the converged SAC policy and (ii) 0.5M non-expert transitions collected from a mid-performance SAC policy, yielding a 50% expert / 50% non-expert composition consistent with the main text. These datasets jointly provide a rich distribution of state–action pairs spanning skill acquisition stages, supporting both imitation and reinforcement learning settings under low-data constraints. C.2 MUJOCO

We further evaluate on MuJoCo continuous-control benchmarks (Todorov et al., 2012) that require generalization across goal-conditioned tasks, including Cheetah-dir, Cheetah-vel, and Ant-dir. 

Dataset construction. For MuJoCo tasks, we follow the standard offline data generation protocol in prior offline RL work (Mitchell et al., 2021), where trajectories are collected by training a policy with SAC (Haarnoja et al., 2018) and applying action penalties to discourage excessively large control inputs. We consider two dataset expertise levels matching the main-text definitions: • Near-Optimal (NO): trajectories generated by a converged expert SAC/TD3 policy, domi-nated by expert behavior. • Sub-Optimal (SO): a mixture of (i) 50% trajectories sampled from the NO dataset and (ii) 50% trajectories collected from mid-performance SAC policies, resulting in a 50% expert / 50% non-expert composition with comparable data volume. These two regimes allow us to systematically evaluate robustness to trajectory quality while keeping the overall data protocol consistent. 

Task families. We evaluate across three MuJoCo benchmarks: • Cheetah-dir: a HalfCheetah agent is conditioned on a discrete direction variable indicating whether it should run forward or backward, with a reward encouraging movement along the specified direction. In the multi-task offline RL setting, training and evaluation are performed on the two direction tasks. In the meta offline RL setting, the agent is trained on one direction and evaluated on the held-out opposite direction. • Cheetah-vel: the agent is conditioned on a target forward velocity and receives a velocity-tracking reward that penalizes deviation from the specified speed. In the multi-task offline 

18 Preprint 

RL setting, the agent is trained and evaluated on all 40 velocity tasks. In the meta offline RL setting, training is conducted on 35 target velocities and evaluation is performed on the remaining 5 unseen velocities. • Ant-dir: the Ant agent is conditioned on a target movement direction in the 2D plane and rewarded for moving toward that direction. In the multi-task offline RL setting, all 50 direction tasks are used for both training and evaluation. In the meta offline RL setting, the agent is trained on 45 directions and evaluated on 5 held-out unseen directions. Overall, these MuJoCo benchmarks complement Meta-World by emphasizing locomotion control and goal-conditioned dynamics, enabling a comprehensive evaluation of LaMA-DT across heterogeneous offline control domains under both NO and SO dataset expertise. 

# D BASELINES 

We compare LaMA-DT against representative multi-task offline RL baselines spanning value-based, behavior-cloning, generative, and Decision-Transformer paradigms. Across all baselines, we use the same task splits and dataset preprocessing as in our main experiments, and we follow the original papers’ recommended architectures and hyperparameters whenever available. 

CDS (Conservative Data Sharing) (Yu et al., 2021). CDS is a representative data sharing baseline for multi-task offline RL. Its key idea is to selectively share transitions across tasks while remaining conservative under distribution shift. In our implementation, we train a single task-conditioned actor 

πθ (a | s, i ) that takes the state s and a task identifier i as input, and outputs the action. 

MTBC (Multi-Task Behavior Cloning). We extend behavior cloning to multi-task offline policy learning by using a task-ID conditioned actor that learns a single policy across all tasks, minimizing the MSE for continuous actions. 

MTIQL (Multi-Task Implicit Q-Learning). IQL (Kostrikov et al., 2021a) learns the value function via expectile regression and trains the actor via advantage-weighted regression, which makes it effective for offline settings without behavior policy constraints as strict as CQL-style methods. MTIQL extends IQL to multi-task learning by using a task-ID conditioned actor and multi-head critic networks. 

MTDIFF (He et al., 2023). MTDIFF is a diffusion-based approach for multi-task RL that uses conditional generative modeling for planning and data synthesis. We use MTDIFF-P as our baseline. 

MTDT (Multi-Task Decision Transformer) (Chen et al., 2021). MTDT extends Decision Trans-former to multi-task data by conditioning the Transformer policy on a task identifier embedding. Trajectories are serialized into token sequences and the model is trained with an autoregressive action prediction objective. At evaluation, MTDT is provided with the task ID and desired return-to-go to generate task-specific actions. 

Prompt-DT (PDT) (Xu et al., 2022). Prompt-DT conditions action generation on trajectory prompts rather than explicit task IDs. A small set of prompt trajectories is prepended to the input sequence, serving as in-context demonstrations of task behavior. The model then predicts actions for the query trajectory conditioned on both the prompt tokens and return-to-go. 

HarmoDT (Hu et al., 2024). HarmoDT is a prompt-based Decision Transformer baseline for multi-task offline RL that mitigates gradient conflicts by learning task-specific parameter masks ,enabling conflict-aware sharing across tasks. We use HarmoDT-F as the HarmoDT baseline. 

Low-data setting. To evaluate data efficiency, we construct low-data regimes by subsampling each task’s offline dataset to a fixed percentage of the original size (e.g., 1%, 5%, 10%). Crucially, we preserve trajectory boundaries during subsampling: instead of randomly shuffling individual transitions across episodes, we sample complete trajectories from the original dataset. This ensures that all sequence-modeling baselines receive consistent temporal structure, and that our six objectives 19 Preprint can be trained properly. While the subsampling percentage is defined with respect to the number of transitions , the actual sampling unit remains a full trajectory (i.e., we include all transitions within each selected episode). For each task, we randomly sample trajectories without replacement until the target percentage is reached, maintaining the same trajectory-level statistics as the full dataset, only scaled down in volume.

Removing discriminative content collapses performance. The No description variant replaces every per-task description with a single shared placeholder, eliminating all inter-task discriminative information. This drops ML30 by 29 .4 pts ( 69 .8 → 40 .4) and Cheetah-dir by 190 .9 (937 .8 → 746 .9), confirming that LaMA-DT’s gains are driven by what the descriptions communicate rather than by the mere presence of language tokens. Without per-task semantic disambiguation, augmentation degenerates into goal-agnostic generation. In summary, LaMA-DT is robust to surface compression and rewording, but degrades smoothly as descriptions lose discriminative content. The implication for practitioners is straightforward: any natural-language summary that clearly distinguishes one task from another suffices, but minimal task names or ungrammatical text carry too little signal for the LLM to ground generation effectively. Adapter count and computational cost. LaMA-DT uses six objective-specific LoRA adapters and one shared adapter in Stage I, followed by one policy adapter in Stage III. These eight adapters are shared across tasks in the main experiments; we do not fine-tune a separate adapter for each task. The 1.24B-parameter language-model backbone remains frozen. Scoring those four candidates under all six objectives takes 1.51 s, or approximately 36% of the combined generation-and-scoring time.
