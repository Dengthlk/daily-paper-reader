## 摘要
多模态网页智能体已展现出通过图形用户界面（GUI）与网站交互的潜力，但现实网页任务往往需要长时程、多步规划，这对单一策略而言仍具挑战性。此类智能体必须联合推断高层计划、在中间状态间导航、在长交互历史中跟踪进度，并执行视觉接地动作。尽管先前工作探索了带有独立规划器的模块化多智能体系统，但规划器通常未与执行器联合更新。我们研究显式分离并联合训练规划与执行能否为长时程网页导航提供更强的归纳偏置。我们提出 JHiMA-WebRL，一种面向网页智能体的联合分层多智能体强化学习框架，将任务分解器与执行器耦合。为训练任务分解器，我们使用强教师模型从多模态 GUI 轨迹中构建结构化子任务监督，并利用这些标注微调任务分解器与子任务条件执行器。随后，我们将 Group Relative Policy Optimization（GRPO）扩展至交互式 WebArena 环境，通过分层 rollout 分组和角色特定优势联合优化任务分解器与执行器。在 WebArena-Lite-v2 上，由 7B 执行器和 7B 任务分解器组成的 JHiMA-WebRL-14B 取得 37.2% 的平均成功率，而 ScaleCUA-32B 智能体在同一训练任务上用 RL 微调并在相同协议下评估，成功率为 24%。消融实验表明，在 RL 期间联合更新任务分解器优于仅更新执行器。这些结果表明，联合学习的角色分解配合较小模型，可作为面向长时程网页任务扩展单一智能体的一种有竞争力的替代方案。

## Abstract
Multimodal web agents have shown promising capabilities for interacting with websites through graphical user interfaces (GUIs), yet realistic web tasks often require long-horizon, multi-step planning that remains challenging for monolithic policies. Such agents must jointly infer high-level plans, navigate through intermediate states, track progress over extended interaction histories, and execute visually grounded actions. Although prior work has explored modular multi-agent systems with a separate planner, the planner is typically not updated jointly with the actor. We investigate whether explicitly separating and jointly training planning and execution provides a stronger inductive bias for long-horizon web navigation. We introduce JHiMA-WebRL, a joint hierarchical multi-agent reinforcement learning framework for web agents that couples a task decomposer with an actor. To train the decomposer, we use a strong teacher model to construct structured subtask supervision from multimodal GUI trajectories, and use these annotations to fine-tune both the decomposer and the subtask-conditioned actor. We then extend Group Relative Policy Optimization (GRPO) to jointly optimize the decomposer and actor in the interactive WebArena environment through hierarchical rollout grouping and role-specific advantages. On WebArena-Lite-v2, JHiMA-WebRL-14B, consisting of a 7B actor and a 7B decomposer, achieves an average success rate of 37.2%, compared with 24% for a ScaleCUA-32B agent that we fine-tune with RL on the same training tasks and evaluate under the same protocol. Ablations show that jointly updating the decomposer during RL outperforms updating the actor alone. These results suggest that jointly learned role factorization with smaller models can be a competitive alternative to scaling monolithic agents for long-horizon web tasks.

- **整体含义**：论文将网页智能体建模为两个可训练角色的协作策略：高层任务分解器负责生成子任务计划，低层 actor 负责在网页中执行 GUI 动作，并通过分层 GRPO 联合优化。

### 2. 方法论

#### 2.1 核心思想

- 将网页交互因子化为两个独立参数化的策略：
  - **分解器** \(\pi_D\)：输入任务指令 \(x\) 和初始截图 \(o_0\)，输出有序子任务序列 \(d=(g_1,\dots,g_L)\)。
  - **执行器/actor** \(\pi_A\)：输入任务、当前截图 \(o_t\)、动作历史 \(h_t\) 和子任务计划 \(d\)，输出下一步 GUI 动作 \(a_t\)。
- 训练分三阶段：
  1. 用强教师模型从多模态 GUI 轨迹自动构造子任务监督；
  2. 对分解器和 actor 分别进行监督微调（SFT）；
  3. 在交互式 WebArena 环境中，用扩展的分层 GRPO 联合优化两个模块。

#### 2.2 分解器数据生成

- 使用 **GPT-5.2-Codex** 作为教师模型，从 ScaleCUA 轨迹中生成结构化子任务标注。
- 输入包括：原始任务指令、起始截图、完整动作序列及对应截图。
- 输出包括：有序可执行子任务列表，以及可选的无用/冗余动作说明。
- 共生成约 **76K** 分解训练样本；数据覆盖 Windows、macOS、Linux、Android、Web 平台，平均子任务数约 2.56。
- 目的：把低层 GUI 演示转化为高层规划监督，使开源分解器无需在推理时依赖专有教师模型。

#### 2.3 监督微调

- **分解器 SFT**：以 Qwen2.5-VL-7B 初始化，输入任务指令和初始截图，预测教师生成的子任务序列，使用标准负对数似然损失。
- **Actor SFT**：同样以 Qwen2.5-VL-7B 初始化，在 ScaleCUA 轨迹及 grounding 数据上微调；与普通 SFT 不同，actor 的上下文中额外加入教师生成的子任务列表，使其学习“在计划条件下执行动作”。
- Actor 训练样本总量为 **2,535,552**，覆盖 web、mobile、desktop 等平台。

#### 2.4 联合分层多智能体 GRPO

- 对每个任务：
  - 分解器采样 **K 个候选分解** \(d_i\)；
  - 对每个分解，actor 执行 **M 条完整环境轨迹** \(\tau_{i,j}\)；
  - 每条轨迹只获得终局二值奖励 \(R_{i,j}\in\{0,1\}\)，不依赖密集过程奖励。
- **Actor 层优势**：在同一个分解 \(d_i\) 下，比较 M 条执行轨迹的终局奖励，做组内标准化，得到 actor 优势 \(A^A_{i,j}\)。这样 actor 更新主要比较“同一计划下的不同执行”。
- **分解器层优势**：对每个分解 \(d_i\)，先计算其 M 条执行轨迹的平均奖励 \(S_i\)，再在 K 个候选分解之间做组内标准化，得到分解器优势 \(A^D_i\)。这样分解器学习“哪些计划更能带来下游成功”。
- **策略优化**：保留 GRPO 的 token 级裁剪目标，分别为 actor 和分解器构造重要性采样比、裁剪损失和 KL 项；最终联合损失为 \(L_{\text{JHiMA}}=L_A+L_D\)。
- 由于两个模块参数不相交，联合损失等价于用同一 rollout 批次分别更新两个模块。
- 实验中移除了标准 GRPO 的标准差归一化和响应长度归一化，依据 Liu et al. (2025c)；附录说明在无标准差归一化时，分解器优势可视为带基线的策略梯度估计，且至多相差正比例因子。
- 实验设置中 KL 系数设为 0，即不使用 KL 惩罚。

### 6. 主要结论与发现

- 显式分离并联合训练任务分解器与执行器，在长时程网页任务上优于仅训练单体 actor 或冻结规划器的模块化方案。
- JHiMA-WebRL-14B 以 7B actor + 7B decomposer 达到 **37.2%** 平均成功率，在同协议受控比较中显著高于 RL 微调的 ScaleCUA-32B（24.0%）。
- 消融表明：
  - 联合更新分解器比冻结分解器只更新 actor 更好（37.2% vs 33.4%）；
  - 去掉分解器和子任务条件后，actor-only RL 为 34.9%–35.2%，低于完整框架；
  - 完全去掉 RL 的 SFT-only 系统为 35.1%，也低于联合 RL 系统。
- 子目标完成比例与最终任务成功具有较强关联，说明分解器生成的子任务可作为有意义的中间里程碑。
- 作者结论是：联合学习的角色分解配合较小模型，可作为扩大单体智能体的一种有竞争力替代方案；但当前结果主要证明环境内收益，尚不能证明跨网站或开放 Web 的泛化优势。

- **消融维度针对核心主张**：冻结分解器、去掉分解器、去掉 RL 等变体分别检验“联合训练”“角色分解”“RL”三个关键因素，实验逻辑与论文主张对应较紧密。
- **补充了计划质量的机制性证据**：除成功率外，还分析子目标完成比例与最终成功的 AUROC、单调关系及 Kendall’s \(\tau\)，使“分解器提供有意义中间里程碑”不只是定性判断。
- **失败分析较具体**：对 Map 域落后给出重复缩放导致步数耗尽的案例，有助于读者理解方法在细粒度视觉定位和动作效率上的边界。
- **算力与训练配置披露较充分**：SFT 的 GPU 型号、并行策略、超参数，以及 RL 的 LoRA 配置、rollout 规模、总 GPU-hours 均有报告，复现信息相对完整。

### 8. 局限与不足

- **评估覆盖面有限**：主实验仅基于 WebArena-Lite-v2 的 154 个任务和五个网站，未在 WebArena 全量、其他网页 benchmark 或真实开放 Web 上验证；结论主要支持“环境内泛化”，不足以证明跨网站、跨任务分布的迁移能力。
- **性能提升幅度与统计可靠性**：完整系统相对冻结分解器、actor-only RL 和 SFT-only 的优势约为 2.0–3.8 个百分点，作者也承认可能受运行间方差影响，但未报告置信区间、标准误或显著性检验；因此消融结论的稳健性仍需更多随机种子验证。
- **基线比较存在异质性**：部分对比数字来自不同论文、不同模型规模、不同评估器和不同交互预算，LLM 模糊匹配 judge 也可能与原始评估器不完全一致；虽然作者提示不能直接横向比较，但读者仍可能高估跨方法差距。
- **训练与测试共享环境结构**：训练任务与评估任务不重叠，但共享 Reddit、GitLab、Shopping 等网站及意图模板，仍属于同一环境族内的泛化；对完全未见网站、动态页面和真实生产系统的表现未知。
- **对教师模型和外部 judge 的依赖**：分解器监督来自 GPT-5.2-Codex，评估成功判定也依赖强 LLM；这会引入教师偏差、评估偏差和成本不可控问题，且论文未量化教师标注与评估推理的成本。
- **RL 训练成本仍较高**：尽管使用 LoRA 和较小模型，联合 RL 仍需约 720 GPU-hours；每任务 K=3、M=7 的 rollout 设计带来较大环境交互开销，实际部署和迭代成本不低。
- **超参数与训练细节的敏感性未充分探索**：K、M、KL 系数、是否使用标准差归一化、步数预算等均可能影响结果；论文将 KL 系数设为 0，也未系统比较不同 KL 设置或奖励塑形方案。
- **Map 域表现暴露视觉接地与动作效率短板**：12.5% 的成功率低于部分基线，说明高层分解并不能完全弥补低层细粒度定位和重复动作控制问题；论文对该失败模式的分析仍以案例为主，缺少系统性诊断。
- **方法适用范围主要限于可分解的网页任务**：对于高度探索性、需要频繁回溯或开放式信息检索的任务，固定先分解再执行的流程可能限制在线适应；论文未讨论分解器在执行中动态重规划的能力。

### 9. 启示与可借鉴之处

- **角色分解是扩大单体智能体之外的一条现实路径**：在参数预算有限时，将高层规划与低层执行分开，并让两个较小模型协作，可能比单纯扩大单体模型更具性价比；但前提是规划器必须可训练、能接收下游执行反馈。
- **层级 GRPO 的优势构造值得复用**：用“同一计划内比较执行”“不同计划间比较平均成功率”的两级组内标准化，把终局二值奖励分配给不同角色，是一种通用性较强的多智能体信用分配思路，可迁移到工具调用、机器人任务分解等场景。
- **自动化计划标注可降低模块化智能体的数据门槛**：从已有轨迹反向生成子任务监督，比人工设计计划模板更具扩展性；未来可进一步结合执行失败信息生成负例或纠正性计划，提升分解器的鲁棒性。
- **评估设计需区分“框架收益”和“模型规模收益”**：本文自行训练同协议基线是值得借鉴的做法；后续工作应进一步报告多种子方差、置信区间和统一 judge 版本，以增强模块化方法比较的可信度。
- **未来方向**：可探索执行中动态重规划、引入轻量过程奖励或子目标验证器、跨 benchmark 与开放 Web 迁移、以及将角色分解扩展到更多异构角色（如检索器、验证器、记忆管理器）；同时应系统分析 K/M 预算与成功率的 scaling 关系。

### 10. 总体评价

论文针对长时程网页智能体中“规划器与执行器未联合优化”的关键问题，提出了清晰的角色分解框架和分层 GRPO 联合训练方法，实验设计在受控基线、消融和子目标质量分析上有较强针对性。其主要贡献在于证明：可训练的任务分解器与执行器通过共享终局奖励联合优化，能在较小参数规模下取得有竞争力的网页任务成功率。与此同时，单 benchmark 评估、较小消融差距、异质基线比较和较高的 RL 交互成本，限制了结论的外推强度。总体而言，这是一项方法动机明确、训练流程完整、实证有说服力但泛化证据仍有限的工作，适合作为模块化多智能体强化学习用于 GUI/网页智能体的参考基线。
